# 版本 26.3

（发布日期）

## 一般新增功能

- 新增用于超大文件的 **快速查看** 模式。快速查看会以只读模式几乎瞬间打开超大文件，而无需将整个文件载入内存：EmEditor 会在后台查找各行的位置，并且只读取当前显示的行。打开文件后，即使 EmEditor 仍在查找行位置，你也可以立即跳转到文档末尾；在行位置查找完成之前不会显示行号。大于 **启用快速查看模式的最小文件大小**（默认 4,096 MB）的文件会自动以快速查看模式打开，并在以快速查看模式打开文件时显示通知。要在普通模式与快速查看模式之间切换，请在 **编辑** 菜单中选择 **快速查看**。{{profree}}
- 在快速查看模式下，你可以：
  - 滚动、移动光标、选择文本（包括纵向选择），以及复制文本（包括 [**复制引用**](../cmd/edit/edit_copy_prefix)）。{{profree}}
  - 使用 [**跳转**](../cmd/edit/jump) 和 [**跳转至标记**](../cmd/edit/tag_jump) 命令跳转到指定行。{{profree}}
  - 亮显 [**高亮 (1)**](../dlg/properties/highlight1/index) 和 [**高亮 (2)**](../dlg/properties/highlight2/index) 页面中的字符串、注释、引号字符串、所选文本和标记，并可用 [**添加至标记**](../cmd/edit/add_to_markers) 命令添加标记。{{profree}}
  - 通过 **查看** 菜单中的 [**标记**](../cmd/view/view_marks) 命令显示换行符、文件结尾、制表符、空格、全角空格和控制字符，并显示 [**标尺**](../cmd/view/view_ruler)。{{profree}}
  - 使用 **查找** 对话框与 **查找** 工具栏查找文本，包括正则表达式以及统计匹配数。{{profree}}
  - 使用 **查找** 对话框中的 [**提取** 按钮](../dlg/find/index) 提取匹配行、文件名及行、文件名或匹配字符串，包括统计高频字符串。{{pro}}
  - 使用“查找”的 **数字范围** 和 **模糊匹配** 选项。{{pro}}
  - 使用 **批处理查找** 对话框中的 [**多项查找前一个** 和 **多项查找下一个** 按钮](../dlg/find/index) 查找多个字符串，包括批处理列表中的链接文件并统计匹配数。{{pro}}
  - 使用 **筛选** 工具栏筛选行，包括列下拉列表、链接文件以及高亮匹配项。筛选时会显示进度对话框。{{pro}}
  - 使用 **筛选** 工具栏的 [**提取所有行**](../cmd/search/filterbar_extract) 和 [**提取匹配字符串**](../cmd/search/filterbar_extract_matches) 命令提取筛选后的行或匹配字符串。{{pro}}
  - 使用 CSV 模式，包括列标题、选择列、调整列宽，以及引号单元格中的换行。{{pro}}
  - 以不同编码重新加载文件，包括 **二进制（ASCII 视图）** 和 **二进制（十六进制视图）**。{{profree}}
  - 使用 **另存为** 以不同编码或不同换行符保存文件。{{profree}}
  - 使用 [**比较** 菜单](../cmd/diff/index)上的命令比较文档，包括 [**同步滚动**](../cmd/diff/sync_scroll_direct) 和 [**拆分视图**](../cmd/diff/split_view_direct)。快速查看模式下的文档也可以与普通模式下的文档进行比较。{{profree}}
  - 在状态栏查看光标位置、字符代码、选区长度，以及所选数字的总和与平均值。{{profree}}
  - 使用 [**大文件控制器**](../cmd/view/large_file_bar) 打开文件的某一部分。{{pro}}
  - 运行宏和插件，例如 **字数统计** 插件。{{pro}}
  - 运行[外部工具](../cmd/external_tools/index)。{{profree}}
  - 使用 [**AI** 菜单](../cmd/ai/index)上的命令，包括 AI 项目。此功能需要 **ChatAI** 插件。{{pro}}
- 在快速查看模式下，**查找** 对话框、**查找** 工具栏以及 **筛选** 工具栏中的 **渐进式搜索** 选项将被禁用。{{profree}}
- 在快速查看模式下，打开超大文件以及在其中进行查找、筛选与提取，比上一版本更快，即使文件远大于物理内存也是如此。请参见下面的测试结果。

### 测试结果：

|  | v26.2 | v26.3 | 对比 |
| --- | --- | --- | --- |
| 打开 | 30.2 秒 | 6.61 秒 | 快 4.57 倍 |
| 查找 “abcde”（统计匹配数） | 37.0 秒 | 7.64 秒 | 快 4.84 倍 |
| 筛选 “abcde” | 69.6 秒 | 7.53 秒 | 快 9.24 倍 |
| 在“查找”对话框中提取 “abcde” | 103 秒 | 9.70 秒 | 快 10.6 倍 |
| 查找 “[a-c]{5}”（正则表达式，统计匹配数） | 198 秒 | 124 秒 | 快 1.60 倍 |

- 随机 ASCII 文件（UTF-8，48.4 GB，10 亿行）、默认选项、Windows 11、Ryzen 9 7950X。
- 96 GB 物理内存，通过 `bcdedit /set {current} truncatememory 17179869184` 限制为 16 GB RAM 以进行模拟。
- v26.3：以快速查看模式打开。

## 新选项

- 在 **自定义** 对话框的 [**高级** 页面](../dlg/customize/advanced/index)新增 **启用快速查看模式的最小文件大小** 文本框。{{profree}}
- 在 [**大文件控制器**](../cmd/view/large_file_bar)中新增 **快速查看模式** 复选框。{{pro}}

## 新增宏功能 {{pro}}

- 在 **Document** 对象中新增 [**FastView** 属性](../macro/document/fast_view)。
- 在 **Document** 对象中新增 [**Text** 属性](../macro/document/text) 与 [**TextLength** 属性](../macro/document/text_length)。
- 在 **WebBar** 对象中新增 [**scrollBy** 方法](../macro/web_bar/scrollby)、[**scrollTo** 方法](../macro/web_bar/scrollto)、[**scrollX** 属性](../macro/web_bar/scrollx) 与 [**scrollY** 属性](../macro/web_bar/scrolly)。
- 现在，在快速查看模式下也可以使用 **Document** 与 **Selection** 对象中不会更改文档的属性与方法。会更改文档的属性与方法在快速查看模式下将失败。

## 插件新功能 {{pro}}

- 为 [**EE_INFO** 消息](../plugin/message/ee_info)新增 **EI_GET_FAST_VIEW** 参数。
- 新增 **EEID_FAST_VIEW** 命令 ID。
- 现在，在快速查看模式下也可以使用用于读取文档或移动光标的消息。会更改文档的消息在快速查看模式下将失败。
- **[资源管理器](../howto/plugin/plugin_explorer)**：该插件现在使用 **自定义** 对话框中 [**窗口** 页面](../dlg/customize/window/index)所指定的对话框字体大小。
- **[与 AI 聊天](../howto/plugin/plugin_chat_with_ai)**
  - 新增按对话（每个聊天）AI 设置。按对话设置仅对单个聊天生效，修改它不会影响全局设置。
  - 在聊天输入框中新增 AI 模型与工具指示器。它会显示当前 AI 模型以及该聊天所选的工具。点击模型名称会打开 **设置** 对话框。
  - 新增 MCP 连接器，用于将 AI 连接到外部服务。目前仅支持 HTTP 服务器（不支持 STDIO 与 SSE 连接）。
  - 在 **设置** 对话框中新增 **MCP 连接器** 页面。你可以使用 MCP 服务器的 JSON 配置添加新的连接器。
  - 新增 **EmEditor 帮助页面** 连接器。AI 可使用该连接器访问最新的 EmEditor 帮助页面，从而给出比网页搜索工具更好的答案。
