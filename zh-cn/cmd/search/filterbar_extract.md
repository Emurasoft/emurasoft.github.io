# 提取所有行 (筛选工具栏) 命令

## 摘要

提取所有筛选出来的行到一个新文档中。

## 说明

将所有筛选出来的行提取到一个新文档中。

此命令也可在快速查看模式下使用。如果筛选仍在运行，EmEditor 会等待筛选完成。

## 运行方法

- 默认菜单: 无
- [所有命令](../tools/all_commands): **搜索**
\> **筛选工具栏** \> **提取所有行**
- 工具栏: ![](../../images/extract_all.png) (筛选工具栏) \> **提取所有行**
- 状态栏: 无
- 默认快捷键: 无

## 插件命令ID

```
EEID_FILTERBAR_EXTRACT (3928)```

## 宏

### \[JavaScript\]

```
editor.ExecuteCommandByID(3928);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 3928
```
