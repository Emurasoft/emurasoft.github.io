# 自定义快速查看命令

## 摘要

打开自定义对话框中的快速查看页面。

## 说明

显示[**自定义** 对话框](../../dlg/customize/index)的 [**快速查看** 页面](../../dlg/customize/fast_view/index)，您可以在其中定义应用程序的通用设置。

## 运行方法

- 默认菜单: 无
- [所有命令](all_commands): **工具** \>
**自定义** \>
**快速查看**
- 工具栏: 无
- 状态栏: 无
- 默认快捷键: 无

## 插件命令ID

```
EEID_CUSTOMIZE_FAST_VIEW (9082)
```

## 宏

### \[JavaScript\]

```
editor.ExecuteCommandByID(9082);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 9082
```
