# 保存差异命令

## 摘要

将快速查看模式的编辑内容和行的位置保存到 EmEditor 数据文件夹中的差异文件，而不重写文件，使文件能更快打开。

## 说明

此命令在快速查看模式下可用。它会将你的编辑内容保存到差异文件，而不重写原文件（对于超大文件，重写可能需要很长时间）。下次打开该文件时，这些编辑内容会被自动应用。要将编辑内容写入文件，请使用 [**保存** 命令](file_save) 的 **保存并立即合并** 来保存文档。

差异文件还会保存该文件中行的位置，使文件打开时无需再次查找行的位置。如果文档没有编辑内容，则只保存行的位置。

差异文件保存在 EmEditor 本地应用程序数据文件夹中的 **FastView** 文件夹中。你可以在 **自定义** 对话框的 [**快速查看** 页面](../../dlg/customize/fast_view/index) 上查看和删除它们。详细信息请参见[以快速查看模式打开和编辑超大文件](../../howto/file/file_fast_view)。

## 运行方法

- 默认菜单: 无
- [所有命令](../tools/all_commands): **文件** \> **差异** \> **保存差异**
- 工具栏: 无
- 状态栏: 无
- 默认快捷键: 无

## 插件命令ID

```
EEID_FAST_VIEW_SAVE_DIFF (23291)
```

## 宏

### \[JavaScript\]

```
editor.ExecuteCommandByID(23291);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 23291
```
