# 载入差异命令

## 摘要

应用保存在快速查看模式文件的差异文件中的编辑内容。

## 说明

此命令在快速查看模式下、且当前文件的差异文件存在时可用。它会应用使用 [**保存差异** 命令](fast_view_save_diff) 或 [**保存** 命令](file_save) 的 **仅保存我的更改** 保存的编辑内容，并关闭 **只读**。如果文档有未保存的编辑内容，EmEditor 会先询问是否保存这些编辑内容。

差异文件中的编辑内容通常会在打开文件时自动应用。你可以使用此命令再次应用它们，例如在放弃了未保存的编辑内容之后。

如果文件在保存差异文件之后被更改、文件以不同的编码打开，或者允许引号内单元格换行的 CSV 设置不同，则无法应用差异文件。详细信息请参见[以快速查看模式打开和编辑超大文件](../../howto/file/file_fast_view)。

## 运行方法

- 默认菜单: 无
- [所有命令](../tools/all_commands): **文件** \> **差异** \> **载入差异**
- 工具栏: 无
- 状态栏: 无
- 默认快捷键: 无

