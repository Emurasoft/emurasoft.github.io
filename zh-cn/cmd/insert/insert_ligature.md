# 插入合字命令

## 摘要

在输入字符 a、o、s、A 或 O 时插入合字

## 说明

在选择这个命令后，在光标处插入一个带有连字符的字符(æ，œ，Æ 或 Œ)通过输入 a, o, A 或 O, 或一个急转的 s (ß)通过输入 s。

## 运行方法

- 默认菜单: **插入** \> **音调符号** \> **连字**
- [所有命令](../tools/all_commands): **插入** \> **音调符号** \> **连字**
- 工具栏: 无
- 状态栏: 无
- 默认快捷键: CTRL+SHIFT+7

## 插件命令ID

```
EEID_INSERT_LIGATURE (4309)```

## 宏

### \[JavaScript\]

```
editor.ExecuteCommandByID(4309);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4309
```
