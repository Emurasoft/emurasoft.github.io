# 快速查看命令

## 摘要

在处理超大文件时，在普通模式和快速查看模式之间切换。

## 说明

以快速查看模式重新打开当前文档；如果文档已经处于快速查看模式，则以普通模式重新打开。快速查看模式可以几乎瞬间打开超大文件，而无需将整个文件载入内存，并且让你能查看、搜索和编辑该文件。详细信息请参见[以快速查看模式打开和编辑超大文件](../../howto/file/file_fast_view)。

大于 **自定义** 对话框中 [**快速查看** 页面](../../dlg/customize/fast_view/index) 上 **启用快速查看模式的最小文件大小** 的文件会自动以快速查看模式打开。

如果文档有未保存的编辑内容，EmEditor 会在切换模式之前询问是否保存这些编辑内容。此命令不适用于未命名的文档。

## 运行方法

- 默认菜单: **编辑** \> **快速查看**
- [所有命令](../tools/all_commands): **编辑** \> **高级** \> **快速查看**
- 工具栏: 无
- 状态栏: 双击 **FAST**
- 默认快捷键: 无

## 插件命令ID

```
EEID_FAST_VIEW (23289)
```

## 宏

### \[JavaScript\]

```
document.FastView = true;
或
document.FastView = false;
```

### \[VBScript\]

```
document.FastView = True
或
document.FastView = False
```
