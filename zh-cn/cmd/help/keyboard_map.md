# 键盘布局命令

## 摘要

显示所有可用的键盘快捷键。

## 说明

显示可用命令的键盘快捷键列表。

## 运行方法

- 默认菜单: **帮助** \> **键盘映射**
- [所有命令](../tools/all_commands): **帮助** \> **键盘映射**
- 工具栏: 无
- 状态栏: 无
- 默认快捷键: 无

## 插件命令ID

```
EEID_KEYBOARD_MAP (4298)```

## 宏

### \[JavaScript\]

```
editor.ExecuteCommandByID(4298);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4298
```
