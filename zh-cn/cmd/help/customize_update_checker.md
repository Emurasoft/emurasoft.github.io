# 自定义更新检查器命令

## 摘要

自定义更新检查器。

## 说明

打开 **更新选项** 对话框，你可以指定 EmEditor 检查更新的次数以及下载和保存路径。

EmEditor (MSI) 的更新检查器将于 2027 年 3 月 31 日 (UTC) 之后停用。在该日期之后，此命令将不可用。

## 运行方法

- 默认菜单: **帮助** \> **自定义更新检查器**
- [所有命令](../tools/all_commands): **帮助** \> **自定义更新检查器**
- 工具栏: 无
- 状态栏: 无
- 默认快捷键: 无

## 插件命令ID

```
EEID_CUSTOMIZE_UPDATE_CHECKER (4482)```

## 宏

### \[JavaScript\]

```
editor.ExecuteCommandByID(4482);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4482
```
