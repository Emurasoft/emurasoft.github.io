# 拆分视图命令

## 摘要

以拆分视图显示最近查看的两个文档。

## 说明

以拆分视图显示最近查看的两个文档，该视图会在同一窗口、同一标签页中将两个文档并排显示。

也可以显示处于快速查看模式的文档。

## 运行方法

- 默认菜单: **比较** \> **拆分视图**
- [所有命令](../tools/all_commands): **比较** \> **拆分视图**
- 工具栏: 无
- 状态栏: 无
- 默认快捷键: 无

## 插件命令ID

```
EEID_SPLIT_VIEW_DIRECT (4085)```

## 宏

## \[JavaScript\]

```
editor.ExecuteCommandByID(4085);
```

## \[VBScript\]

```
editor.ExecuteCommandByID 4085
```
