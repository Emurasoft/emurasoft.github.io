# 下一单元格命令

## 摘要

CSV、TSV或DSV模式下跳转至下一单元格。

## 说明

在 CSV 模式下跳转至下一单元格。

## 运行方法

- 默认菜单: 无
- [所有命令](../tools/all_commands): **CSV** \> **下一单元格**
- 工具栏: 无
- 状态栏: 无
- 默认快捷键: ALT+SHIFT+向右键

## 插件命令ID

```
EEID_NEXT_CELL (4490)```

## 宏

### \[JavaScript\]

```
editor.ExecuteCommandByID(4490);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4490
```
