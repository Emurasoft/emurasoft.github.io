# Insert category

|     |     |
| --- | --- |
| **[Time and Date](insert_date)** | Inserts the date and time. |
| **[Date and Time](insert_date_time)** | Inserts the date and time. |
| **[Insert Grave](insert_grave)** | Inserts a character with a grave accent by typing a, e, i, o, u, A, E, I, O, U, \` or ". |
| **[Insert Acute](insert_acute)** | Inserts a character with an acute accent by typing a, d, e, i, o, u, y, A, D, E, I, O, U, Y, ' or ". |
| **[Insert Circumflex](insert_circumflex)** | Inserts a character with a circumflex accent by typing a, e, i, o, u, A, E, I, O or U. |
| **[Insert Tilde](insert_tilde)** | Inserts a character with a tilde by typing a, n, o, A, N or O. |
| **[Insert Diaeresis](insert_diaeresis)** | Inserts a character with a diaeresis by typing a, e, i, o, u, y, A, E, I, O, U or Y. |
| **[Insert Ring](insert_ring_above)** | Inserts a character with a ring above by typing a, A or space. |
| **[Insert Ligature](insert_ligature)** | Inserts a ligature by typing a, o, s, A or O. |
| **[Insert Cedilla](insert_cedilla)** | Inserts a c/C character with a cedilla by typing c or C. |
| **[Insert Stroke](insert_stroke)** | Inserts a character with a stroke by typing o, O or c. |
| **[Insert Caron](insert_caron)** | Inserts a character with a caron by typing a, i, o, u, A, I, O, or U. |
| **[Insert Macron](insert_macron)** | Inserts a character with a macron accent by typing a letter. |
| **[Insert Inverted Question Mark](insert_inverted_question)** | Inserts an inverted question mark. |
| **[Insert Inverted Exclamation Mark](insert_inverted_exclamation)** | Inserts an inverted exclamation mark. |

| **[Numbering](numbering)** | Inserts numbering at the cursor position or in a vertical selection. |
| **[AutoFill/AutoRepeat](auto_fill)** | Continues a series or pattern into neighboring cells, lines, or characters. |
| **[Insert Line Above](line_open_above)** | Inserts a new line above the cursor. |
| **[Insert Line Below](line_open_below)** | Inserts a new line below the cursor. |
| **[Duplicate Line](duplicate_line)** | Duplicates the current logical line. |
| **[Insert CR](insert_cr)** | Inserts a CR at the cursor. |
| **[Insert LF](insert_lf)** | Inserts an LF at the cursor. |
| **[Insert CR+LF](insert_cr_lf)** | Inserts a carriage return and line feed at the cursor. |
| **[Insert Tab](insert_tab)** | Inserts a tab at the cursor. |
| **[Insert/Overwrite](insert)** | Toggles insert/overwrite mode. |
| **[Insert](file_insert)** | Inserts a specified file at the current cursor position. |
| [**Insert Snippet**](insert_snippet1) | Inserts a specified snippet at the current cursor position (multiple items). |
