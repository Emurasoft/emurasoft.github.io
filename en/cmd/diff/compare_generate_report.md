# Generate Report command

## Summary

Generates a report file based on the current comparison results.

## Description

Generates a report file based on the current comparison result.

## How to Run

- Default Menu: **Compare** \> **Generate Report**
- [All Commands](../tools/all_commands): **Compare** \> **Generate Report**
- Toolbar: None
- Status Bar: None
- Default Keyboard Shortcut: None

## Plug-in Command ID

```
EEID_COMPARE_GENERATE_REPORT (3996)```

## Macros

### \[JavaScript\]

```
editor.ExecuteCommandByID(3996);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 3996
```
