# CSV category

|     |     |
| --- | --- |
| **[Normal Mode](mode_normal)** | Exits separated value view mode. |
| **[CSV Mode](mode_csv)** | Switches to CSV (comma-separated) mode. |
| **[TSV Mode](mode_tsv)** | Switches to TSV (tab-separated) mode. |
| **[User-Defined DSV Mode](mode_dsv)** | Switches to user-defined DSV (delimiter-separated) mode. |
| **[CSV (multiple items)](sv_mode)** | Shows the document as the specified separated value mode (multiple items). |
| **[Cell Selection Mode](csv_cell_mode)** | Toggles cell selection mode in CSV documents. |
| **[Hide Quotes Temporarily](csv_hide_quotes)** | Temporarily shows the current CSV document without quotation marks or escape characters. |
| **[Column Header](header_toggle)** | Shows or hides the column header. |
| **[Use One-Based Numerical Characters for Column Header](header_num)** | Uses one-based numbering for the column header. |
| **[Use Alphabetical Characters for Column Header](header_alpha)** | Uses alphabetical characters for the column header. |
| **[Use Zero-Based Numerical Characters for Column Header](header_zero_base)** | Uses zero-based numbering for the column header. |
| **[Toggle Headings (Freeze or Unfreeze Panes)](heading_toggle)** | Freezes or unfreezes panes above and to the left of the current cell. |
| **[Set Headings (Freeze Panes)](heading_set)** | Freezes panes above and to the left of the current cell. |
| **[Column Heading 0](heading_reset)** | Unfreezes panes. |
| **[Column Heading 1](heading_1)** | Freezes the first line as headings. |
| **[Column Heading 2](heading_2)** | Freezes the first two lines as headings. |
| **[Column Heading 3](heading_3)** | Freezes the first three lines as headings. |
| **[Column Heading 4](heading_4)** | Freezes the first four lines as headings. |
| **[Row Heading 0](row_heading_reset)** | Unfreezes row headings. |
| **[Row Heading 1](row_heading_1)** | Freezes the first column as row headings. |
| **[Row Heading 2](row_heading_2)** | Freezes the first two columns as row headings. |
| **[Row Heading 3](row_heading_3)** | Freezes the first three columns as row headings. |
| **[Row Heading 4](row_heading_4)** | Freezes the first four columns as row headings. |
| **[Read Only in Column Headings](read_only_headings)** | Toggles the option to make column headings read-only. |
| **[Heading (Pop-up)](heading_popup)** | Shows a pop-up menu to set headings. |
| **[Convert to CSV (multiple items)](convert_to_sv)** | Converts the current separated value document or fixed width column document to the specified separated value document (multiple items). |
| **[Convert to Fixed Width Columns](convert_to_fixed_width)** | Converts the current separated value document to fixed-width columns using the current separator positions. |
| **[CSV Converter](csv_converter)** | Shows or hides the CSV Converter. |
| **[Adjust Separator Positions (Whole Document)](adjust_column)** | Adjusts all separator positions in the CSV document. |
| **[Adjust Separator Positions (Visible Lines Only)](adjust_column_visible)** | Adjusts separator positions in visible lines only in a CSV document. |
| **[Hide Columns](hide_column)** | Hides the selected columns or the current column. |
| **[Unhide Columns](unhide_column)** | Unhides the selected columns or the current column. |
| **[Reset Column Width](reset_column_width)** | Resets the width of the selected columns in a CSV document. |
| **[Align Left](align_left)** | Aligns text in the selected columns, or the current column, to the left. |
| **[Align Center](align_center)** | Centers text in the selected columns, or the current column. |
| **[Align Right](align_right)** | Aligns text in the selected columns, or the current column, to the right. |
| **[Select CSV Column without Headings](select_column)** | Selects the current column (excluding headings) in vertical selection mode. |
| **[Select CSV Column with Headings](select_column_with_headings)** | Selects the current column with headings in vertical selection mode. |
| **[Insert Column Left](insert_column)** | Inserts a new column to the left of the current column in a separated value document. |
| **[Insert Column Right](insert_column_right)** | Inserts a new column to the right of the current column in a separated value document. |
| **[Add Column](add_column)** | Adds a new column to the right of the last column in a separated value document. |
| **[Duplicate Columns](duplicate_column)** | Duplicates the selected columns in a CSV document. |
| **[Move/Copy Columns](move_column)** | Moves or copies selected columns, or the current column, to the specified position in a CSV document. |
| **[Manage Columns](manage_columns)** | Moves, copies, deletes, or sorts columns in the CSV document. |
| **[Combine Columns](combine_columns)** | Combines selected columns in a CSV document. |
| **[Split Columns](split_column)** | Splits the selected columns in a CSV document. |
| **[Make Number of Columns Same](make_columns_same)** | Makes the number of columns the same in a CSV document. |
| **[Remove Unnecessary Quotes](remove_unnecessary_quotes)** | Removes unnecessary double quotes in a CSV document. |
| **[Remove Embedded Newline Characters in CSV](remove_embedded_nl)** | Removes embedded newline characters in CSV documents. |
| **[Quote All Cells](add_quotes)** | Encloses all cells in a CSV document in double quotes. |
| **[Combine Lines](combine_lines)** | Combines vertically adjacent duplicate cells in a CSV document. |
| **[Flash Fill (Cell Selection Mode Only)](flash_fill)** | Automatically fills values in the entire column of a CSV document. |
| **[Transpose](transpose)** | Swaps rows and columns in the CSV document. |
| **[Pivot Table](pivot_table)** | Creates a pivot table in the CSV document. |
| **[Unpivot](unpivot)** | Converts columns into rows by unpivoting the CSV data. |
| [**Join CSV**](join_csv) | Joins two CSV documents. |
| [**Extract Columns**](extract_columns) | Extracts specified columns from the current CSV document. |
| **[Automatically Add Separators](auto_add_separators)** | Automatically detects and adds separators in Normal mode to prepare for conversion to fixed-width columns. |
| **[Add/Remove Separator](add_remove_separator)** | Adds or removes a separator at the cursor position (or the position pointed to on the ruler) in Normal mode to prepare for conversion to fixed-width columns. |
| **[Remove All Separators](remove_all_separators)** | Removes all separators in Normal mode. |
| **[Columns/Separators (Pop-up Menu)](sv_sep_popup)** | Shows a pop-up menu for working with columns and separators. |
| **[Edit Cell (Cell Selection Mode Only)](csv_edit_cell)** | Edits the current cell in a CSV document. |
| **[Clear Contents (Cell Selection Mode Only)](clear_contents)** | Clears the contents of the selection in the CSV document. |
| **[Next Cell (Cell Selection Mode Only)](csv_next_cell)** | Jumps to the next cell in the CSV document. |
| **[Previous Cell (Cell Selection Mode Only)](csv_prev_cell)** | Jumps to the previous cell in the CSV document. |
| **[Cell Above (Cell Selection Mode Only)](csv_up)** | Jumps to the cell above in the CSV document. |
| **[Cell Below (Cell Selection Mode Only)](csv_down)** | Jumps to the cell below in the CSV document. |
| **[Right Edge (Cell Selection Mode Only)](right_edge)** | Moves to the right edge of the current data region. |
| **[Left Edge (Cell Selection Mode Only)](left_edge)** | Moves to the left edge of the current data region. |
| **[Top Edge (Cell Selection Mode Only)](top_edge)** | Moves to the top edge of the current data region. |
| **[Bottom Edge (Cell Selection Mode Only)](bottom_edge)** | Moves to the bottom edge of the current data region. |
| **[Right Edge Extend (Cell Selection Mode Only)](shift_right_edge)** | Extends the selection to the right edge of the current data region. |
| **[Left Edge Extend (Cell Selection Mode Only)](shift_left_edge)** | Extends the selection to the left edge of the current data region. |
| **[Top Edge Extend (Cell Selection Mode Only)](shift_top_edge)** | Extends the selection to the top edge of the current data region. |
| **[Bottom Edge Extend (Cell Selection Mode Only)](shift_bottom_edge)** | Extends the selection to the bottom edge of the current data region. |
| **[Select Cell](select_cell)** | Selects the cell at the cursor in CSV, TSV, or DSV mode. |
| **[Next Cell](next_cell)** | Jumps to the next cell in CSV, TSV, or DSV mode. |
| **[Previous Cell](prev_cell)** | Jumps to the previous cell in CSV, TSV, or DSV mode. |
| **[CSV (Pop-up Menu)](sv_popup)** | Shows a pop-up menu to select a CSV mode. |
