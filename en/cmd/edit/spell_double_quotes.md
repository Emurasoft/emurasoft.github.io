# Check Spelling in String Enclosed by Double Quotation Marks command

## Summary

Checks spelling in strings enclosed in double quotation marks.

## Description

Checks spelling in string enclosed by double quotation marks. Misspelled words will be underlined in red.

## How to Run

- Default Menu: **Edit** \> **Spelling** \> **Check Spelling in** \> **Strings Enclosed in Double Quotation Marks**
- [All Commands](../tools/all_commands): **Edit** \> **Spelling** \> **Check Spelling in** \> **Strings Enclosed in Double Quotation Marks**
- Toolbar: None
- Status Bar: None
- Default Keyboard Shortcut: None

## Plug-in Command ID

```
EEID_SPELL_DOUBLE_QUOTES (4515)```

## Macros

### \[JavaScript\]

```
editor.ExecuteCommandByID(4515);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4515
```
