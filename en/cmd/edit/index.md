# Edit category

|     |     |
| --- | --- |

| **[Undo All](undo_all)** | Undoes all previous actions. |

| **[Copy Link](edit_copy_link)** | Copies a hyperlink to the Clipboard. |
| **[Auto Copy](auto_copy)** | Toggles auto copy mode. |
| **[Paste](edit_paste)** | Inserts the contents of the Clipboard at the cursor position. |
| **[Paste as System Default Encoding](edit_paste_ansi)** | Pastes the contents of the Clipboard using the [system default encoding](../../glossary/index). |
| **[Paste as HTML](paste_html)** | Pastes the contents of the Clipboard as HTML. |

| **[Show Clipboard History](clipboard_history)** | Shows the Clipboard history. |
| **[Restore Deleted String](restore_deleted)** | Restores previously deleted text at the cursor position. |
| **[Delete](delete)** | Deletes the selection, or deletes one character to the right of the cursor. |
| **[Delete Left Character](back)** | Deletes the selection, or deletes one character to the left of the cursor. |
| **[Delete Completely](delete_complete)** | Deletes the selection. |
| **[Delete Lines](delete_line)** | Deletes the selected lines or the current line. |
| **[Delete Right Line](delete_right_line)** | Deletes text to the right of the cursor on the current line. |
| **[Delete Left Line](delete_left_line)** | Deletes text to the left of the cursor on the current line. |
| **[Delete Word](delete_word)** | Deletes the word at the cursor. |

| **[Delete Left Word](delete_left_word)** | Deletes the word to the left of the cursor. |
| **[Delete Columns](delete_column)** | Deletes the selected columns or the current column. |
| **[Delete Spaces at End of Lines](trim_right)** | Deletes extra spaces at the end of all lines in the current document. |

| **[Char Left](left)** | Moves the cursor one character to the left. |
| **[Word Right](right_word)** | Moves the cursor one word to the right. |

| **[Logical Home](logical_home)** | Moves the cursor to the start of the current logical line. |

| **[Logical End](logical_end)** | Moves the cursor to the end of the current logical line. |

| **[Find Matching Tag](next_tag)** | Moves the cursor to the matching tag. |

| **[Window Right](window_right)** | Moves the cursor to the right edge of the current window. |
