# Customize Fast View command

## Summary

Opens the Fast View page of the Customize dialog box.

## Description

Displays the [**Fast View** page](../../dlg/customize/fast_view/index) of the [**Customize** dialog box](../../dlg/customize/index),
where you can define common application settings.

## How to Run

- Default Menu: None
- [All Commands](all_commands): **Tools** >
**Customize** >
**Fast View**
- Toolbar: None
- Status Bar: None
- Default Shortcut Key: None

## Plug-in Command ID

```
EEID_CUSTOMIZE_FAST_VIEW (9082)
```

## Macros

### \[JavaScript\]

```
editor.ExecuteCommandByID(9082);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 9082
```
