# Auto Save Properties command

## Summary

Auto Save properties for the current configuration.

## Description

Displays the [**Auto Save** page](../../dlg/properties/autosave/index) of the **[Configuration Properties](../../dlg/properties/index)**
dialog box.

## How to Run

- Default Menu: None
- [All Commands](all_commands): **Tools** >
**Properties for Current Configuration** \> **Auto Save**
- Toolbar: None
- Status Bar: None
- Default Shortcut Key: None

## Plug-in Command ID

```
EEID_PROPERTY_AUTO_SAVE (8964)```

## Macros

### \[JavaScript\]

```
editor.ExecuteCommandByID(8964);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 8964
```
