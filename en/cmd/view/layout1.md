# Layout command

## Summary

Toggles this layout.

## Description

Toggles this layout (multiple items).

## How to Run

- Default Menu: **View** \> **Layouts** \> (**Layout**)
- [All Commands](../tools/all_commands): **View** \> **Layouts** \> (**Layout**)
- Toolbar: None
- Status Bar: None
- Default Shortcut Key: F11

## Plug-in Command ID

```
EEID_LAYOUT1 (22592)
```

## Macros

### \[JavaScript\]

```
editor.ExecuteCommandByID(22592);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 22592
```
