# Clear Markers for Saved Lines command

## Summary

Clears all markers that indicate saved lines.

## Description

Clears all markers indicating saved lines.

## How to Run

- Default Menu: None
- [All Commands](../tools/all_commands): **View** \> **Clear Markers for Saved Lines**
- Toolbar: None
- Status Bar: None
- Default Shortcut Key: None

## Plug-in Command ID

```
EEID_CLEAR_SAVED_MARKERS (4011)```

## Macros

### \[JavaScript\]

```
editor.ExecuteCommandByID(4011);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4011
```
