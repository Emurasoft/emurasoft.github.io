# Macros category

|     |     |
| --- | --- |
| **[Start/Stop Macro Record](quick_macro_record)** | Starts or stops macro recording. |
| **[Start Recording](record_no_mouse)** | Starts recording a macro, excluding mouse and keyboard actions. |
| **[Run Macro](quick_macro_run)** | Runs a macro. |
| **[Run Macro with Temporary Options](macro_run_options)** | Runs a macro with temporary options. |
| **[Run Clipboard Macro](macro_run_clipboard)** | Runs the clipboard macro. |
| **[Stop Macro](macro_stop)** | Stops the macro. |
| **[Save Macro](macro_save)** | Saves a recorded macro. |
| **[Edit Macro](macro_edit)** | Edits the currently selected macro. |
| **[Select Macro](macro_select)** | Selects a macro. |
| **[Select This Macro](macro_select_this)** | Sets the current file as the active macro. |
| **[Customize Macros](customize_macro)** | Customizes macros. |
| **[Customize Macros - My Macros](customize_macro_my_macros)** | Displays the Customize Macros dialog box and selects the My Macros tab. |
| **[Customize Macros - Options](customize_macro_options)** | Displays the Customize Macros dialog box and selects the Options tab. |
| **[Macro Reference](macro_help)** | Displays the EmEditor macro reference. |
| **[Find Macro Keyword](macro_help_word)** | Searches help topics for the selected macro keyword. |
| **[Macros List](macro1)** | Runs a specified macro in My Macros list (multiple items). |
