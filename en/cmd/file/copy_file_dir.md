# Copy File Folder Path command

## Summary

Copies the full path of the current file's folder to the Clipboard.

## Description

Copies the folder path of the file and put it on the Clipboard. This
command cannot be selected if the document is untitled.

## How to Run

- Default Menu: None
- [All Commands](../tools/all_commands): **File** \> **Copy**
\> **Copy File Folder Path**
- Toolbar: None
- Status Bar: None
- Default Shortcut Key: None

## Plug-in Command ID

```
EEID_COPY_FILE_DIR (4327)```

## Macros

### \[JavaScript\]

```
document.CopyPath();
```

### \[VBScript\]

```
document.CopyPath
```
