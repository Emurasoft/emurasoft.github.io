# Version 26.4

October 21, 2026

## General New Features

- [Fast View mode](../howto/file/file_fast_view) now supports editing. You can edit a huge file without loading it into memory, including typing, pasting, [**Undo**](../cmd/edit/edit_undo)/[**Redo**](../cmd/edit/edit_redo), **Replace All**, multiple selections, and most commands on the **Insert**, **Convert**, and **Sort** menus. The original file does not change until you save it. {{profree}}
- Fast View mode now supports the CSV commands that change the document, including cell editing, [**Split Column**](../cmd/csv/split_column), [**Combine Columns**](../cmd/csv/combine_columns), [**Combine Lines**](../cmd/csv/combine_lines), [**Hide Quotes Temporarily**](../cmd/csv/csv_hide_quotes), [**Hide/Unhide Columns**](../cmd/csv/hide_column), [**Reset Column Width**](../cmd/csv/reset_column_width), and [**Align Left**](../cmd/csv/align_left)/[**Center**](../cmd/csv/align_center)/[**Right**](../cmd/csv/align_right) commands. {{pro}}
- When you save a huge file in Fast View mode, you can merge the edits into the file, or save only the changes to a diff file and leave the original file untouched. The diff file also keeps the positions of the lines, so the file opens instantly the next time, even if it is smaller than the minimum file size. {{profree}}
- Fast View documents are now included in workspaces, including their unsaved edits. {{profree}}
- Added the **FAST** indicator to the status bar and a lightning bolt icon to the document tab in Fast View mode. Double-click the indicator to switch between the normal mode and Fast View mode. {{profree}}
- For details, including the features that are not available in Fast View mode, see [To Open and Edit Huge Files in Fast View Mode](../howto/file/file_fast_view).
- The Start window now supports **App theme** and **Very dark**.
- Macros are now saved as UTF-8 with a signature (BOM) instead of UTF-16.
- Store and MSIX versions: EmEditor now offers to remove file associations left by an uninstalled MSI version, which prevented Windows from opening those files with EmEditor.
- Synchronizing settings through a Microsoft account is no longer available, because Windows 11 no longer syncs the roaming folder of Store apps between computers. Use a sync folder instead. Synchronization with a sync folder is now faster and more reliable: it no longer sends settings that did not change, no longer overwrites newer settings that another computer sent, and does not make EmEditor wait when the folder cannot be reached. See the [**Sync** page](../dlg/customize/sync/index) of the **Customize** dialog box.
- Workspaces are now saved and loaded more safely: a failed save no longer destroys the previous workspace, a broken workspace or a workspace saved by a newer version is no longer cleared, and a workspace with more than one window is now saved correctly.
- The Update Checker for the MSI version of EmEditor is retired after March 31, 2027 (UTC). After that date, EmEditor no longer checks for updates, and [**Check for Updates**](../cmd/help/check_updates) and [**Customize Update Checker**](../cmd/help/customize_update_checker) are unavailable.
- The **Registration Information** dialog box now displays the email address of a per-machine registration.
- Smaller installed files. pcre.dll, zlib1.dll, vccorlib140.dll, and msvcp140.dll are no longer installed, and most of the DLLs, the EXE files, and the plug-ins are smaller. In total, the EXE and DLL files are 30% smaller. See the file sizes below.
- Fixed the following problems:
  - Multiple selections whose carets are out of order could corrupt the text or crash EmEditor.
  - EmEditor could crash at the first paint of a line that has a very large number of combining characters.
  - **Sort** and **Delete Duplicate Lines** lost an empty line that follows a line that ends with CR alone.
  - A Markdown file whose name contains "+", or whose folder name contains "#", "?", or "%", was not previewed correctly in the Markdown preview.
  - A snippet that runs a command whose output is a single line, such as the Calculator snippet, crashed EmEditor.
- Faster startup. In our test, the main window is ready 1.93 times faster. Other operations are faster, too. Opening a huge file is faster the second time because the diff file contains the positions of the lines. See the test results below.

## New Commands

- Added the [**Save Diff**](../cmd/file/fast_view_save_diff), [**Load Diff**](../cmd/file/fast_view_load_diff), and [**Discard Diff**](../cmd/file/fast_view_discard_diff) commands to the **File** \> **Diff** submenu of the **All Commands** menu. {{profree}}
- Added the [**Customize Fast View**](../cmd/tools/customize_fast_view) command. {{pro}}
- Added the `emeditor /register` and `emeditor /unregister` [commands](../howto/file/file_commandline.md) for per-machine registration. {{pro}}

## New Options

- Added the [**Fast View** page](../dlg/customize/fast_view/index) to the **Customize** dialog box. The **Minimum file size to enable Fast View mode** text box has moved to this page from the **Advanced** page. The page also lists the diff files, and you can delete them. {{pro}}
- Added the **Prompt when saving a huge file in Fast View mode**, **Save only the changes to a diff file when saving a huge file in Fast View mode**, and **Save the line positions of huge files so they open instantly next time** options to the [**Fast View** page](../dlg/customize/fast_view/index) of the **Customize** dialog box. {{pro}}
- Added the **Fast View mode** item to the [**Status** page](../dlg/customize/status/index) of the **Customize** dialog box. {{pro}}

## New Macro Features {{pro}}

- Added the [**GetFastViewDiffPath** method](../macro/editor/get_fast_view_diff_path) to the **Editor** object.
- Most properties and methods of the **Document** and **Selection** objects that change the document can now be used in Fast View mode.

## Plug-in New Features {{pro}}

- The **Chat with AI** bar now opens on the left side by default.
- Added the **EI_GET_FAST_VIEW_DIFF_PATH** parameter to the [**EE_INFO** message](../plugin/message/ee_info), and the [**FAST_VIEW_DIFF_PATH_INFO** structure](../plugin/structure/fast_view_diff_path_info).
- Added the **EEID_FAST_VIEW_SAVE_DIFF**, **EEID_FAST_VIEW_LOAD_DIFF**, **EEID_FAST_VIEW_DISCARD_DIFF**, and **EEID_CUSTOMIZE_FAST_VIEW** command IDs.
- Most messages that change the document can now be used in Fast View mode.

### Notes

- This update addresses the [eMudhra Intermediate CA Compromise](https://emudhra.we-have-a-problem.com/), a critical security issue. The LSP feature uses Node.js which was vulnerable to this issue, so we have updated the bundled Node.js to [v26.12.1](TODO add node release notes) to address the issue. 
  - We performed a full security scan of the EmEditor source code and found that LSP was the only affected area. No other part of EmEditor is vulnerable as long as your Windows system has the latest updates. EmEditor uses the Windows CA certificates rather than bundling its own. The WebPreview and ChatAI plug-ins use the Microsoft Edge installed on your system. Thus, we recommend updating Windows and your web browser as soon as possible.
