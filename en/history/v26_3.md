# Version 26.3

(release date)

## General New Features

- Added **Fast View** mode for huge files. Fast View opens a huge file almost instantly in read-only mode without loading the whole file into memory: EmEditor finds the positions of the lines in the background, and reads only the lines that are displayed. You can jump to the end of the document immediately after you start opening a file, while EmEditor is still finding the positions of the lines; the line numbers are not displayed until the positions are found. Files larger than the **Minimum file size to enable Fast View mode** (4,096 MB by default) are opened in Fast View mode automatically, and a notification appears when a file is opened in Fast View mode. To switch between the normal mode and Fast View mode, select **Fast View** on the **Edit** menu. {{profree}}
- In Fast View mode, you can:
  - Scroll, move the cursor, select text including vertical selection, and copy text, including [**Copy in Quotes**](../cmd/edit/edit_copy_prefix). {{profree}}
  - Jump to a line with the [**Jump**](../cmd/edit/jump) and [**Tag Jump**](../cmd/edit/tag_jump) commands. {{profree}}
  - Highlight the strings of the [**Highlight (1)**](../dlg/properties/highlight1/index) and [**Highlight (2)**](../dlg/properties/highlight2/index) pages, comments, quoted strings, the selected text, and markers, and add markers with the [**Add to Markers**](../cmd/edit/add_to_markers) command. {{profree}}
  - Show newline characters, the end of file, tabs, spaces, wide spaces, and control characters with the [**Marks**](../cmd/view/view_marks) commands on the **View** menu, and show the [**Ruler**](../cmd/view/view_ruler). {{profree}}
  - Find text with the **Find** dialog box and the **Find** toolbar, including regular expressions and counting the matches. {{profree}}
  - Extract the matched lines, the file names and the lines, the file name, or the matched strings with the [**Extract** button](../dlg/find/index) of the **Find** dialog box, including counting frequent strings. {{pro}}
  - Use the **Number range** and **Fuzzy** options of Find. {{pro}}
  - Find multiple strings with the [**Multi-Find Previous** and **Multi-Find Next** buttons](../dlg/find/index) of the **Batch Find** dialog box, including linked files in the batch list and counting the matches. {{pro}}
  - Filter the lines with the **Filter** toolbar, including the column drop-down list, linked files, and highlighting the matches. A progress dialog box appears while filtering. {{pro}}
  - Extract the filtered lines or the matched strings with the [**Extract All Lines**](../cmd/search/filterbar_extract) and [**Extract Matched Strings**](../cmd/search/filterbar_extract_matches) commands of the **Filter** toolbar. {{pro}}
  - Use CSV modes, including the column headings, selecting columns, adjusting the column widths, and newlines in quoted cells. {{pro}}
  - Reload the file in a different encoding, including **Binary (ASCII View)** and **Binary (Hexadecimal View)**. {{profree}}
  - Save the file with **Save As** in a different encoding or with different newline characters. {{profree}}
  - Compare documents with the commands on the [**Compare** menu](../cmd/diff/index), including [**Synchronize Scrolling**](../cmd/diff/sync_scroll_direct) and [**Split View**](../cmd/diff/split_view_direct). A document in Fast View mode can also be compared with a document in the normal mode. {{profree}}
  - See the cursor position, the character code, the length of the selection, and the sum and average of the selected numbers on the status bar. {{profree}}
  - Open a portion of the file with the [**Large File Controller**](../cmd/view/large_file_bar). {{pro}}
  - Run macros and plug-ins, such as the **Word Count** plug-in. {{pro}}
  - Run [external tools](../cmd/external_tools/index). {{profree}}
  - Use the commands on the [**AI** menu](../cmd/ai/index), including the AI items. This feature requires the **ChatAI** plug-in. {{pro}}
- In Fast View mode, the **Incremental search** options of the **Find** dialog box, the **Find** toolbar, and the **Filter** toolbar are disabled. {{profree}}

## New Options

- Added the **Minimum file size to enable Fast View mode** text box to the [**Advanced** page](../dlg/customize/advanced/index) of the **Customize** dialog box. {{profree}}
- Added the **Fast View mode** check box to the [**Large File Controller**](../cmd/view/large_file_bar). {{pro}}

## New Macro Features {{pro}}

- Added the [**FastView** property](../macro/document/fast_view) to the **Document** object.
- Added the [**Text** property](../macro/document/text) and the [**TextLength** property](../macro/document/text_length) to the **Document** object.
- Added the [**scrollBy** method](../macro/web_bar/scrollby), the [**scrollTo** method](../macro/web_bar/scrollto), the [**scrollX** property](../macro/web_bar/scrollx), and the [**scrollY** property](../macro/web_bar/scrolly) to the **WebBar** object.
- The properties and methods of the **Document** and **Selection** objects that do not change the document can now be used in Fast View mode. Properties and methods that change the document fail in Fast View mode.

## Plug-in New Features {{pro}}

- Added the **EI_GET_FAST_VIEW** parameter to the [**EE_INFO** message](../plugin/message/ee_info).
- Added the **EEID_FAST_VIEW** command ID.
- The messages that read the document or move the cursor can now be used in Fast View mode. Messages that change the document fail in Fast View mode.

### Notes

- \[P\] EmEditor Professional only
- \[PF\] EmEditor Professional and EmEditor Free
