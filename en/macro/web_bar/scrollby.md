# scrollBy Method (WebBar Object)

Scrolls the window by the specified relative amount.

## 

### \[JavaScript\]

```
WebBar.scrollBy( dx, dy );
```

### \[VBScript\]

```
WebBar.scrollBy dx, dy
```

## Parameters

_dx_

Specifies a horizontal amount to scroll.

_dy_

Specifies a vertical amount to scroll.

## Version

Supported on EmEditor Professional Version 26.3 or later.
