# scrollBy Method (WebBar Object)

Scrolls the window to the specified position.

## 

### \[JavaScript\]

```
WebBar.scrollTo( x, y );
```

### \[VBScript\]

```
WebBar.scrollTo x, y
```

## Parameters

_x_

Specifies a horizontal position to scroll to.

_y_

Specifies a vertical position to scroll to.

## Version

Supported on EmEditor Professional Version 26.3 or later.
