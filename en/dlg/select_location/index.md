# Select Location dialog box

This dialog box appears when the [**Hyperlink** command](../../cmd/edit/markdown_hyperlink) or the [**Image** command](../../cmd/edit/markdown_image) is selected. You can specify the location to insert.

## Location text box

Specifies the location, usually a URL or a path. When the dialog box opens, the text on the clipboard is pasted here.

## Browse Local Files button

Allows you to select a local file. Its path, relative to the folder of the current document, is entered in the **Location** text box.
