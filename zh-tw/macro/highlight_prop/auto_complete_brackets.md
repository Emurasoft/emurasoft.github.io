# AutoCompleteBrackets 屬性 (HighlightProp 對象)

與組態屬性中 [**亮顯 (2)** 頁面](../../dlg/properties/highlight2/index) 上的 **自動完成括號/引號標記** 核取方塊相對應。

## 

### \[JavaScript\]

```
b = object.AutoCompleteBrackets;
object.AutoCompleteBrackets = b;
```

### \[VBScript\]

```
b = object.AutoCompleteBrackets
object.AutoCompleteBrackets = b
```

## 版本

支持 EmEditor 7.00 或之後的版本。
