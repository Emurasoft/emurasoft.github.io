# 分割檢視命令

## 摘要

以分割視圖顯示最近檢視的兩個文檔。

## 說明

以分割視圖顯示最近檢視的兩個文檔，該視圖會在同一視窗、同一標籤頁中將兩個文檔並排顯示。

也可以顯示處於快速檢視模式的文檔。

## 運行方法

- 預設功能表: **比較** \> **分割檢視**
- [全部命令](../tools/all_commands): **比較** \> **分割檢視**
- 工具列: 無
- 狀態列: 無
- 預設快速鍵: 無

## 外掛程式命令ID

```
EEID_SPLIT_VIEW_DIRECT (4085)```

## 巨集

### \[JavaScript\]

```
editor.ExecuteCommandByID(4085);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4085
```
