# 忽略換行字元命令

## 摘要

比較文件時忽略每行的換行字元。

## 說明

比較文檔時忽略換行符。

## 運行方法

- 預設功能表: **比較** \> **忽略換行字元**
- [全部命令](../tools/all_commands): **比較** \> **忽略換行字元**
- 工具列: 無
- 狀態列: 無
- 預設捷徑: 無

## 外掛程式命令ID

```
EEID_IGNORE_RETURNS (4502)```

## 巨集

### \[JavaScript\]

```
editor.ExecuteCommandByID(4502);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4502
```
