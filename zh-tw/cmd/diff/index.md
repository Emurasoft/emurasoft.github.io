# 比較類別

|     |     |
| --- | --- |
| **[比較](compare_direct)** | 不指定選項的情況下，比較最近檢視的兩個文件。 |
| **[按選項進行比較](compare_options)** | 指定選項的情況下，比較最近檢視的兩個文件。 |
| **[重新掃描](compare_rescan)** | 重新掃描比較的文件並重新整理結果。 |
| **[同步捲動](sync_scroll_direct)** | 不指定選項的情況下，同步捲動最近檢視的兩個文件。 |
| **[按參數同步捲動](sync_scroll_options)** | 啟動同步捲動精靈以同步捲動最近檢視的兩個文件。 |
| **[分割檢視](split_view_direct)** | 在一個視窗中分割顯示兩個最近查看的文件。 |
| **[重設](compare_reset)** | 重設比較或同步捲動模式並清除比較結果。 |
| **[忽略前置空格](ignore_lead_space)** | 比較文件時忽略每行的前置空格。 |
| **[忽略尾端空格](ignore_trail_space)** | 比較文件時忽略每行的尾端空格。 |
| **[忽略內嵌空格](ignore_embedded_space)** | 比較文件時忽略每行的內嵌空格。 |
| **[忽略大小寫](ignore_cases)** | 比較文件時忽略大小寫。 |
| **[忽略換行字元](ignore_returns)** | 比較文件時忽略每行的換行字元。 |
| **[忽略註解](ignore_comment)** | 比較文件時忽略註解。 |
| **[忽略編碼](ignore_encoding)** | 比較文件時忽略編碼。 |
| **[同步垂直捲動](sync_vert)** | 同步垂直捲動。 |
| **[同步水平捲動](sync_horz)** | 同步水平捲動。 |
| **[同步游標位置](sync_caret)** | 同步游標位置。 |
| **[完成後還原視窗位置](sync_restore_pos)** | 比較或同步完成後還原視窗位置。 |
| **[儲存選項](compare_save_options)** | 儲存選項以比較或同步捲動。 |
| **[上一更改](compare_prev)** | 跳至上一更改。 |
| **[下一更改](compare_next)** | 跳躍到下一更改。 |
| **[上一更改行](compare_prev_line)** | 轉到上一更改的行。 |
| **[下一更改行](compare_next_line)** | 轉到下一更改的行。 |
| **[上一更改的字元](compare_prev_char)** | 跳轉到上一更改的字元處。 |
| **[下一更改的字元](compare_next_char)** | 跳轉到下一更改的字元處。 |
| **[為有更改的行添加書籤](compare_bookmark)** | 為全部有更改的行添加書籤。 |
| **[生成報告](compare_generate_report)** | 根據目前的比較結果生成報告檔案。 |
| **[跳轉到其他](compare_jump_to_other)** | 跳轉到正在與目前的文件比較或捲動的另一個文件。 |
| **[複製到另一窗格](copy_to_other)** | 將此文件中的這個變更複製到另一窗格的文件中。 |
| **[全部複製到另一窗格](copy_all_to_other)** | 將此文件中的全部變更複製到另一窗格的文件中。 |
