# 新增檔案，貼為引文並包含換行字元命令

## 摘要

新增一個檔案, 把剪貼簿內容貼為引文並包含換行字元。

## 說明

這個命令等同于 [**新文字檔** 命令](file_new) 加 [**貼為引文並包含換行字元** 命令](../edit/paste_prefix_return)。

## 運行方法

- 預設功能表: 無
- [全部命令](../tools/all_commands): **檔案** \> **新增** \> **新增檔案，貼為引文並包含換行字元**
- 工具列: 無
- 狀態列: 無
- 預設捷徑: 無

## 外掛程式命令ID

```
EEID_NEW_PASTE_PREFIX_RETURN (4272)```

## 巨集

## \[JavaScript\]

```
editor.ExecuteCommandByID(4272);
```

## \[VBScript\]

```
editor.ExecuteCommandByID 4272
```
