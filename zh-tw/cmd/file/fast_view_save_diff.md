# 儲存差異命令

## 摘要

將快速檢視模式的編輯內容和行的位置儲存至 EmEditor 資料資料夾中的差異檔，而不重寫檔案，讓檔案能更快開啟。

## 說明

此命令可在快速檢視模式中使用。它會將您的編輯內容儲存至差異檔，而不重寫原始檔案（對於巨型檔案，重寫可能需要很長的時間）。下次開啟該檔案時，會自動套用這些編輯內容。若要將編輯內容寫入檔案，請使用 [**儲存** 命令](file_save) 的 **儲存並立即合併** 儲存文檔。

差異檔也會儲存檔案中各行的位置，因此開啟檔案時無需再次尋找各行的位置。如果文檔沒有編輯內容，則只會儲存行的位置。

差異檔儲存在 EmEditor 本機應用程式資料資料夾的 **FastView** 資料夾中。您可以在 **自訂** 對話方塊的 [**快速檢視** 頁面](../../dlg/customize/fast_view/index) 上檢視和刪除差異檔。詳細資訊請參見[在快速檢視模式中開啟和編輯巨型檔案](../../howto/file/file_fast_view)。

## 運行方法

- 預設功能表: 無
- [全部命令](../tools/all_commands): **檔案** \> **差異** \> **儲存差異**
- 工具列: 無
- 狀態列: 無
- 預設捷徑: 無

## 外掛程式命令ID

```
EEID_FAST_VIEW_SAVE_DIFF (23291)
```

## 巨集

### \[JavaScript\]

```
editor.ExecuteCommandByID(23291);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 23291
```
