# 載入差異命令

## 摘要

套用儲存在快速檢視模式檔案之差異檔中的編輯內容。

## 說明

此命令可在快速檢視模式中，當目前檔案的差異檔存在時使用。它會套用使用 [**儲存差異** 命令](fast_view_save_diff) 或 [**儲存** 命令](file_save) 的 **僅儲存我的變更** 所儲存的編輯內容，並關閉 **唯讀**。如果文檔有未儲存的編輯內容，EmEditor 會先詢問是否要儲存。

開啟檔案時，通常會自動套用差異檔中的編輯內容。您可以使用此命令再次套用這些編輯內容，例如在捨棄未儲存的編輯內容之後。

如果檔案在儲存差異檔之後已變更、以不同的編碼開啟，或允許引號儲存格內換行的 CSV 設定不同，則無法套用差異檔。詳細資訊請參見[在快速檢視模式中開啟和編輯巨型檔案](../../howto/file/file_fast_view)。

## 運行方法

- 預設功能表: 無
- [全部命令](../tools/all_commands): **檔案** \> **差異** \> **載入差異**
- 工具列: 無
- 狀態列: 無
- 預設捷徑: 無

## 外掛程式命令ID

```
EEID_FAST_VIEW_LOAD_DIFF (23292)
```

## 巨集

### \[JavaScript\]

```
editor.ExecuteCommandByID(23292);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 23292
```
