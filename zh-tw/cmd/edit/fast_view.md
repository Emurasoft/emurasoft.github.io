# 快速檢視命令

## 摘要

在一般模式與巨型檔案的快速檢視模式之間切換。

## 說明

以快速檢視模式重新開啟目前的文檔；如果文檔已處於快速檢視模式，則以一般模式重新開啟。快速檢視模式幾乎能瞬間開啟巨型檔案，而無需將整個檔案載入記憶體，並讓您能檢視、搜尋和編輯該檔案。詳細資訊請參見[在快速檢視模式中開啟和編輯巨型檔案](../../howto/file/file_fast_view)。

大於 **自訂** 對話方塊中 [**快速檢視** 頁面](../../dlg/customize/fast_view/index) 上的 **啟用快速檢視模式所需的最小檔案大小** 的檔案，會自動以快速檢視模式開啟。

如果文檔有未儲存的編輯內容，EmEditor 會在切換模式之前詢問是否要儲存。此命令不適用於未命名的文檔。

## 運行方法

- 預設功能表: **編輯** \> **快速檢視**
- [全部命令](../tools/all_commands): **編輯** \> **進階** \> **快速檢視**
- 工具列: 無
- 狀態列: 雙擊 **FAST**
- 預設捷徑: 無

## 外掛程式命令ID

```
EEID_FAST_VIEW (23289)
```

## 巨集

### \[JavaScript\]

```
document.FastView = true;
或
document.FastView = false;
```

### \[VBScript\]

```
document.FastView = True
或
document.FastView = False
```
