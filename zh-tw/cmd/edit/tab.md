# Tab鍵或增加行縮排命令

## 摘要

插入一個Tab字元，或增加行縮排。

## 說明

在游標處插入一個 Tab (tab 字元)。如果多行被選取了，這個命令將在所有選取行的行首插入一個 Tab。

## 運行方法

- 預設功能表: 無
- [全部命令](../tools/all_commands): **編輯** \> **水平移動游標** \> **插入Tab鍵/增加行縮排**
- 工具列: 無
- 狀態列: 無
- 預設鍵盤快速鍵: TAB

## 外掛程式命令ID

```
EEID_TAB (4188)```

## 巨集

## \[JavaScript\]

```
editor.ExecuteCommandByID(4188);
```

## \[VBScript\]

```
editor.ExecuteCommandByID 4188
```
