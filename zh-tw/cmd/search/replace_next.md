# 取代下一個命令

## 摘要

取代下一個符合並再次尋找符合。

## 說明

用同樣的參數，取代之前搜尋過的字串的下一個符合的結果

## 運行方法

- 預設功能表: 無
- [全部命令](../tools/all_commands): **搜尋** \> **尋找/取代** \> **取代下一個**
- 工具列: 無
- 狀態列: 無
- 預設捷徑: 無

## 外掛程式命令ID

```
EEID_REPLACE_NEXT (4447)```

## 巨集

### \[JavaScript\]

```
editor.ExecuteCommandByID(4447);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4447
```
