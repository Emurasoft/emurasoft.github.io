# 擷取符合字串 (篩選工具列) 命令

## 摘要

擷取符合的字串到新的文件中。

## 說明

將符合的字串抽出到新文檔中。

此命令也可在快速檢視模式下使用。如果篩選仍在運行，EmEditor 會等待篩選完成。

## 運行方法

- 預設功能表: 無
- [全部命令](../tools/all_commands): **搜尋** \> **篩選工具列** \> **擷取符合字串**
- 工具列: ![](../../images/extract_all.png) (篩選工具列) \> **抽出符合字串**
- 狀態列: 無
- 預設快速鍵: 無

## 外掛程式命令ID

```
EEID_FILTERBAR_EXTRACT_MATCHES (4084)```

## 巨集

### \[JavaScript\]

```
editor.ExecuteCommandByID(4084);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4084
```
