# 最上層顯示-開啟命令

## 摘要

顯示這個視窗總是在最上層。

## 說明

總是將目前的視窗置頂顯示。其他文檔將一直在被設置為總是置頂的文檔下方顯示。

## 運行方法

- 預設功能表: 無
- [全部命令](../tools/all_commands): **視窗** \> **最上層顯示** \> **最上層顯示-開啟**
- 工具列: 無
- 狀態列: 無
- 預設捷徑: 無

## 外掛程式命令 ID

- EEID\_WINDOW\_ALWAYS\_TOP\_ON (4343)

## 巨集

## \[JavaScript\]

```
editor.ExecuteCommandByID(4343);
```

## \[VBScript\]

```
editor.ExecuteCommandByID 4343
```
