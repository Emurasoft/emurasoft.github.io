# 最上層顯示-關閉命令

## 摘要

不會顯示這個視窗總是在最上層。

## 說明

解除目前的視窗總是置頂的狀態。其他文檔將一直在被設置為總是置頂的文檔下方顯示。

## 運行方法

- 預設功能表: 無
- [全部命令](../tools/all_commands): **視窗** \> **最上層顯示** \> **最上層顯示-關閉**
- 工具列: 無
- 狀態列: 無
- 預設捷徑: 無

## 外掛程式命令 ID

- EEID\_WINDOW\_ALWAYS\_TOP\_OFF (4344)

## 巨集

### \[JavaScript\]

```
editor.ExecuteCommandByID(4344);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4344
```
