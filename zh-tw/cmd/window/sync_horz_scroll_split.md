# 當分割時同步水平捲軸命令

## 摘要

同步分隔視窗的水平捲軸。

## 說明

同步分割視窗的水平捲動。

## 運行方法

- 預設功能表: **視窗** \> **分割時同步水平捲動**
- [全部命令](../tools/all_commands): **視窗** \> **分割** \> **分割時同步水平捲動**
- 工具列: 無
- 狀態列: 無
- 預設捷徑: 無

## 外掛程式命令 ID

- EEID\_SYNC\_HORZ\_SCROLL\_SPLIT (4523)

## 巨集

### \[JavaScript\]

```
editor.ExecuteCommandByID(4523);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4523
```
