# 視窗類別

|     |     |
| --- | --- |
| **[最上層顯示](window_always_top)** | 總是將該視窗顯示在最上層。 |
| **[最上層顯示-開啟](window_always_top_on)** | 顯示這個視窗總是在最上層。 |
| **[最上層顯示-關閉](window_always_top_off)** | 不會顯示這個視窗總是在最上層。 |
| **[還原視窗位置](restore_pos)** | 將視窗還原到上次儲存的位置。 |
| **[還原索引標籤視窗位置](restore_combined_pos)** | 還原索引標籤視窗到先前儲存的位置。 |
| **[分割](window_split)** | 分割目前的視窗到窗格中。 |
| **[水平分割](window_split_horz)** | 水平分割目前的視窗。 |
| **[垂直分割](window_split_vert)** | 垂直分割目前的視窗。 |
| **[水平分割並固定位置](window_split_horz_fix)** | 水平分割目前的視窗至指定位置。 |
| **[垂直分割並固定位置](window_split_vert_fix)** | 垂直分割目前的視窗到指定位置。 |
| **[移除分割](window_delete_panes)** | 移除分割。 |
| **[切換水平分割](window_split_horz_toggle)** | 切換水平視窗分割。 |
| **[切換垂直分割](window_split_vert_toggle)** | 切換垂直視窗分割。 |
| **[當分割時同步水平捲軸](sync_horz_scroll_split)** | 同步分隔視窗的水平捲軸。 |
| **[當分割時同步垂直捲軸](sync_vert_scroll_split)** | 同步分隔視窗的垂直捲軸。 |
| **[新增群組](new_group)** | 從群組視窗中卸離目前的文件為一個新的群組。 |
| **[新增群組並最小化](new_group_minimize)** | 從群組視窗中卸離目前的文件為一個新的群組並最小化。 |
| **[新增重疊顯示群組](new_group_cascade)** | 從群組視窗中卸離目前的文件為一個新的群組並排列視窗使之重疊。 |
| **[新增水平群組](new_group_horz)** | 從群組視窗中卸離目前的文件為一個新的群組並水平平鋪排列視窗。 |
| **[新增垂直群組](new_group_vert)** | 從群組視窗中卸離目前的文件為一個新的群組並垂直平鋪排列視窗。 |
| **[移動到上一組](move_prev_group)** | 移動目前的文件到上一個群組中。 |
| **[移動到下一組](move_next_group)** | 移動目前的文件到下一個群組中。 |
| **[關閉目前的群組](group_close_all)** | 關閉目前的群組中的所有文件。 |
| **[關閉目前的群組中的所有其他文件](group_close_others)** | 關閉目前的群組中除目前的文件外的所有其他文件。 |
| **[關閉目前的群組中所有左側的文件](group_close_left)** | 關閉目前的群組中目前的文件左側的所有文件視窗。 |
| **[關閉目前的群組中所有右側的文件](group_close_right)** | 關閉目前的群組中目前的文件右側的所有文件視窗。 |
| **[下一窗格](next_pane)** | 切換到下一窗格。 |
| **[上一窗格](prev_pane)** | 切換到上一窗格。 |
| **[下一窗格或自訂列](next_pane_or_bar)** | 轉到下一窗格或自訂列。 |
| **[上一窗格或自訂列](prev_pane_or_bar)** | 轉到上一窗格或自訂列。 |
| **[活動窗格](active_pane)** | 切換到活動窗格。 |
| **[左側自訂欄](left_custom_bar)** | 切換到左側的自訂欄。 |
| **[頂部自訂欄](top_custom_bar)** | 切換到頂部的自訂欄。 |
| **[右側自訂欄](right_custom_bar)** | 切換到右側的自訂欄。 |
| **[底部自訂欄](bottom_custom_bar)** | 切換到底部的自訂欄。 |
| **[自訂欄選項](pane_menu)** | 顯示快顯功能表以設定自訂欄選項。 |
| **[啟用索引標籤](window_combine)** | 啟用索引標籤對視窗進行合併或停用索引標籤分割所有視窗。 |
| **[允許索引標籤-開](window_combine_on)** | 啟用索引標籤合併所有視窗。 |
| **[允許索引標籤-關](window_combine_off)** | 停用索引標籤分割所有視窗。 |
| **[捲動至左邊緣](scroll_left_edge)** | 捲動到文件的左邊緣。 |
| **[捲動至右邊緣](scroll_right_edge)** | 捲動到文件的右邊緣。 |
| **[向左翻頁](scroll-pageleft)** | 把文件向左捲動一頁。 |
| **[向右翻頁](scroll-pageright)** | 把文件向右捲動一頁。 |
| **[向左捲動](scroll_left)** | 將文件向左捲動一個字元。 |
| **[向右捲動](scroll_right)** | 將文件向右捲動一個字元。 |
| **[捲動至頂部](scroll-top)** | 捲動到文件的頂部。 |
| **[捲動至底部](scroll-bottom)** | 捲動到文件的底部。 |
| **[向上翻頁](scroll-pageup)** | 把文件向上捲動一頁。 |
| **[向下翻頁](scroll-pagedown)** | 把文件向下捲動一頁。 |
| **[向上捲動一行](scroll_up)** | 將文件向上捲動一行。 |
| **[向下捲動一行](scroll_down)** | 將文件向下捲動一行。 |
| **[顯示/隱藏垂直捲軸上的標記](scroll_marks_toggle)** | 顯示或隱藏垂直捲軸上的標記。 |
| **[迷你地圖](minimap_toggle)** | 切換迷你地圖。 |
| **[停留時顯示迷你地圖](minimap_hover)** | 當滑鼠停留在垂直捲軸上時顯示迷你地圖。 |
| **[放大迷你地圖](minimap_zoom_in)** | 放大迷你地圖。 |
| **[縮小迷你地圖](minimap_zoom_out)** | 縮小迷你地圖。 |
| **[顯示整個地圖](minimap_entire_map)** | 顯示整個迷你地圖。 |
| **[重疊視窗](window_cascade)** | 排列視窗使之重疊。 |
| **[水平平鋪視窗](window_tile_horz)** | 水平平鋪排列視窗，使其不重疊。 |
| **[垂直平鋪視窗](window_tile_vert)** | 垂直平鋪排列視窗，使其不重疊。 |
| **[全部最小化](window_minimize_all)** | 最小化所有視窗。 |
| **[下一個](next_window)** | 切換到下一個文件。 |
| **[上一個](prev_window)** | 切換到上一個文件。 |
| **[最近存取的文件](next_zorder_doc)** | 切換到最近存取的文件。 |
| **[最久未存取的文件](prev_zorder_doc)** | 切換到最久未存取的文件。 |
| **[右邊的文件](right_doc)** | 切換至索引標籤列右邊的文件。 |
| **[左邊的文件](left_doc)** | 切換至索引標籤列左邊的文件。 |
| **[移動到下一個](window_move_next)** | 移動目前的文件到下一索引標籤位置。 |
| **[移動到上一個](window_move_prev)** | 移動目前的文件到上一索引標籤位置。 |
| **[文檔清單](window_menu)** | 切換到指定的文檔 (多個項目) 。 |
