# 左邊的文件命令

## 摘要

切換至索引標籤列左邊的文件。

## 說明

把文檔切換到標籤欄上目前的打開的文檔的右邊。

## 運行方法

- 預設功能表: 無
- [全部命令](../tools/all_commands): **視窗** \> **文件導覽** \> **左邊的文件**
- 工具列: 無
- 狀態列: 無
- 預設捷徑: CTRL + SHIFT + F6

## 外掛程式命令 ID

- EEID\_LEFT\_DOC (4548)

## 巨集

### \[JavaScript\]

```
editor.ExecuteCommandByID(4548);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4548
```
