| --- | --- |

| **[TSV 模式](../csv/mode_tsv)** | 選擇 TSV ( Tab分隔) 模式。 |
| **[使用者自訂的 DSV 模式](../csv/mode_dsv)** | 選擇使用者自訂的 DSV (分隔符號分隔) 模式。 |
| **[CSV (多個條目)](../csv/sv_mode)** | 把文檔顯示為指定的分隔值模式 (多個條目)。 |
| **[儲存格選擇模式](../csv/csv_cell_mode)** | 在 CSV 文件中切換儲存格選擇模式。 |
| **[暫時隱藏引號](../csv/csv_hide_quotes)** | 暫時顯示目前的 CSV 文件，不具引號或逸出字元。 |
| **[欄標題](../csv/header_toggle)** | 顯示或隱藏欄標題。 |
| **[用基底為1的數字字元作為欄標題](../csv/header_num)** | 使用基底為1的數字字元作為欄標題。 |
| **[用字母字元作為欄標題](../csv/header_alpha)** | 使用字母字元作為欄標題。 |
| **[用基底為0的數字字元作為欄標題](../csv/header_zero_base)** | 使用基底為0的數字字元作為欄標題。 |
| **[顯示或隱藏標題（凍結或取消凍結窗格）](../csv/heading_toggle)** | 將目前的儲存格上方的列和左側的欄設定或重設為不可捲動。 |
| **[設定標題（凍結窗格）](../csv/heading_set)** | 將目前的儲存格上方的列和左側的欄設定為不可捲動。 |
| **[欄標題 0](../csv/heading_reset)** | 重設欄標題。 |
| **[欄標題 1](../csv/heading_1)** | 把第一列作為標題並且固定不捲動。 |
| **[欄標題 2](../csv/heading_2)** | 把前兩列作為標題並且固定不捲動。 |
| **[欄標題 3](../csv/heading_3)** | 把前三列作為標題並且固定不捲動。 |
| **[欄標題 4](../csv/heading_4)** | 把前四列作為標題並且固定不捲動。 |
| **[列標題 0](../csv/row_heading_reset)** | 重設列標題。 |
| **[列標題 1](../csv/row_heading_1)** | 把第一欄作為標題並且固定不捲動。 |
| **[列標題 2](../csv/row_heading_2)** | 把前兩欄作為標題並且固定不捲動。 |
| **[列標題 3](../csv/row_heading_3)** | 把前三欄作為標題並且固定不捲動。 |
| **[列標題 4](../csv/row_heading_4)** | 把前四欄作為標題並且固定不捲動。 |
| **[欄標題唯讀](../csv/read_only_headings)** | 切換選項使欄標題唯讀。 |
| **[標題 (快顯)](../csv/heading_popup)** | 顯示一個設定標題的快顯功能表。 |
| **[轉換為 CSV (多個條目)](../csv/convert_to_sv)** | 把目前的含有分隔值的文檔或固定欄寬文檔轉換為指定的分隔值文檔 (多個項目)。 |
| **[固定欄寬](../csv/convert_to_fixed_width)** | 用目前的分隔符號位置把目前的含有分隔值的文件轉換為固定欄寬。 |
| **[CSV 轉換器](../csv/csv_converter)** | 顯示或隱藏 CSV 轉換器。 |
| **[調整分隔符號位置 (整個文件)](../csv/adjust_column)** | 調整 CSV 文件中的分隔符號位置。 |
| **[調整分隔符號位置 (僅可見行)](../csv/adjust_column_visible)** | 僅在 CSV 文件的可見行上調整分隔符號位置。 |
| **[隱藏欄](../csv/hide_column)** | 隱藏選取的欄或目前欄。 |
| **[取消隱藏欄](../csv/unhide_column)** | 顯示選取欄之間的隱藏欄。 |
| **[重設欄寬](../csv/reset_column_width)** | 重設 CSV 文件中所選欄的寬度。 |
| **[靠左對齊](../csv/align_left)** | 把選取的欄或目前的欄中的文字靠左對齊。 |
| **[置中對齊](../csv/align_center)** | 把選取的欄或目前的欄中的文字置中對齊。 |
| **[靠右對齊](../csv/align_right)** | 把選取的欄或目前的欄中的文字靠右對齊。 |
| **[選取不帶標題的 CSV 欄](../csv/select_column)** | 在 CSV 文件中用垂直選擇模式選取目前不帶標題的欄。 |
| **[選取帶標題的 CSV 欄](../csv/select_column_with_headings)** | 在 CSV 文件中用垂直選擇模式選取目前帶標題的欄。 |
| **[在左邊插入一欄](../csv/insert_column)** | 在含有分隔值的文件中的目前的欄的左邊插入新的一欄。 |
| **[在右邊插入一欄](../csv/insert_column_right)** | 在含有分隔值的文件中的目前的欄的右邊插入新的一欄。 |
| **[添加欄](../csv/add_column)** | 在含有分隔值的文件中的最後一欄的右邊添加新的一欄。 |
| **[重複欄](../csv/duplicate_column)** | 重複 CSV 文件中選取的欄。 |
| **[移動/複製欄](../csv/move_column)** | 將 CSV 文件中選取的欄或目前的欄移動或複製到指定位置。 |
| **[合併欄](../csv/combine_columns)** | 合併 CSV 文件中選取的欄。 |
| **[分割欄](../csv/split_column)** | 分割 CSV 文件中選取的欄。 |
| **[使欄數相同](../csv/make_columns_same)** | 使 CSV 文件中的欄數相同。 |
| **[刪除不需要的引號](../csv/remove_unnecessary_quotes)** | 刪除 CSV 文件中不需要的雙引號。 |
| **[在 CSV 中刪除內嵌換行字元](../csv/remove_embedded_nl)** | 在 CSV 文件中刪除內嵌換行字元。 |
| **[添加引號到所有儲存格上](../csv/add_quotes)** | 添加雙引號到 CSV 文件中的所有儲存格上。 |
| **[合併行](../csv/combine_lines)** | 合併 CSV 文件中垂直相鄰的重複儲存格。 |
| **[快速填入 (僅限儲存格選擇模式)](../csv/flash_fill)** | 自動填滿 CSV 文件的整個欄中的值。 |
| **[轉置](../csv/transpose)** | 切換 CSV 文件的資料列和資料欄。 |
| **[樞紐分析表](../csv/pivot_table)** | 在 CSV 文件中建立樞紐分析表。 |
| **[取消樞紐](../csv/unpivot)** | 透過取消樞紐 CSV 資料將欄轉換為列。 |
| [合併 CSV](../csv/join_csv) | 合併兩個 CSV 文檔。 |
| [抽出列](../csv/extract_columns) | 從目前的 CSV 文檔中抽出指定列。 |
| **[自動添加分隔符號](../csv/auto_add_separators)** | 自動檢測並添加分隔符號當在標準模式下準備轉換為固定欄寬模式時。 |
| **[添加/刪除分隔符號](../csv/add_remove_separator)** | 在游標位置處(或在尺規上所指的位置處)添加或刪除一個分隔符號當在標準模式下準備轉換為固定欄寬模式時。 |
| **[刪除所有分隔符號](../csv/remove_all_separators)** | 刪除所有分隔符號當在標準模式下時。 |
| **[欄/分隔符號 (快顯功能表)](../csv/sv_sep_popup)** | 顯示一個設定欄或分隔符號選項的快顯功能表。 |
| **[編輯儲存格 (僅限儲存格選擇模式)](../csv/csv_edit_cell)** | 在 CSV 文件中編輯目前的儲存格。 |
| **[清除內容 (僅限儲存格選擇模式)](../csv/clear_contents)** | 清除 CSV 文件中所選區域的內容。 |
| **[下一個儲存格（僅限儲存格選擇模式）](../csv/csv_next_cell)** | 在 CSV 文件中跳轉到下一個儲存格。 |
| **[上一個儲存格（僅限儲存格選擇模式）](../csv/csv_prev_cell)** | 在 CSV 文件中跳轉到上一個儲存格。 |
| **[上方儲存格（僅限儲存格選擇模式）](../csv/csv_up)** | 在 CSV 文件中跳轉到上面的儲存格。 |
| **[下方儲存格（僅限儲存格選擇模式）](../csv/csv_down)** | 在 CSV 文件中跳轉到下方儲存格。 |
| **[右邊緣 (僅限儲存格選擇模式)](../csv/right_edge)** | 移動到目前的資料區域的右邊緣。 |
| **[左邊緣 (僅限儲存格選擇模式)](../csv/left_edge)** | 移動到目前的資料區域的左邊緣。 |
| **[上邊緣 (僅限儲存格選擇模式)](../csv/top_edge)** | 移動到目前的資料區域的上邊緣。 |

| **[延伸到左邊緣 (僅限儲存格選擇模式)](../csv/shift_left_edge)** | 把選區延伸到目前的資料區域的左邊緣。 |
| **[延伸到上邊緣 (僅限儲存格選擇模式)](../csv/shift_top_edge)** | 把選區延伸到目前的資料區域的上邊緣。 |
| **[延伸到下邊緣 (僅限儲存格選擇模式)](../csv/shift_bottom_edge)** | 把選區延伸到目前的資料區域的下邊緣。 |
