# 巨集類別

|     |     |
| --- | --- |
| **[開始/停止巨集記錄](quick_macro_record)** | 開始或停止記錄巨集。 |
| **[開始錄製](record_no_mouse)** | 開始錄製一個巨集(不包括滑鼠或鍵盤動作)。 |
| **[執行巨集](quick_macro_run)** | 執行巨集。 |
| **[使用臨時選項執行巨集](macro_run_options)** | 使用臨時選項執行巨集。 |
| **[執行剪貼簿巨集](macro_run_clipboard)** | 執行剪貼簿巨集。 |
| **[停止巨集](macro_stop)** | 停止巨集。 |
| **[儲存巨集](macro_save)** | 儲存一個已記錄的巨集。 |
| **[編輯巨集](macro_edit)** | 編輯目前的選取的巨集。 |
| **[選擇巨集](macro_select)** | 選擇一個巨集。 |
| **[選擇該巨集](macro_select_this)** | 把開啟的檔案設為目前的巨集。 |
| **[自訂巨集](customize_macro)** | 自訂巨集。 |
| **[自訂巨集 - 我的巨集](customize_macro_my_macros)** | 顯示自訂巨集對話方塊並選擇我的巨集索引標籤。 |
| **[自訂巨集 - 選項](customize_macro_options)** | 顯示自訂巨集對話方塊並選擇選項索引標籤。 |
| **[巨集參考](macro_help)** | 顯示 EmEditor 巨集參考。 |
| **[找到巨集關鍵字](macro_help_word)** | 尋找選取巨集的關鍵字的說明主題。 |
| **[巨集清單](macro1)** | 在我的巨集清單中運行一個指定的巨集 (多個項目) 。 |
