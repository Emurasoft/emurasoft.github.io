# 按文字長度從短到長排序命令

## 摘要

把目前的欄中的文字按長度從短到長排序。

## 說明

在目前的欄中按文字長度從短到長排序文字。在 **自訂** 對話方塊中 **排序** 頁面上的 **當按長度排序時，將全形字元作為 2 個字元排序** 核取方塊定義了全形字元的計算方式。

## 運行方法

- 預設功能表: **排序** \> **按文字長度從短到長排序**
- [全部命令](../tools/all_commands): **排序** \> **按文字長度從短到長排序**
- 工具列: ![](../../images/sort_length_a.png)
- 狀態列: 無
- 預設快速鍵: 無

## 外掛程式命令ID

```
EEID_SORT_LENGTH_A (3917)```

## 巨集

### \[JavaScript\]

```
editor.ExecuteCommandByID(3917);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 3917
```
