# 自訂快速檢視命令

## 摘要

開啟自訂對話方塊中的快速檢視頁面。

## 說明

顯示讓你能定義通用應用設定的 [**自訂** 對話方塊](../../dlg/customize/index) 中的 [**快速檢視** 頁面](../../dlg/customize/fast_view/index)。

## 運行方法

- 預設功能表: 無
- [所有命令](all_commands): **工具** >
**自訂** >
**快速檢視**
- 工具列: 無
- 狀態列: 無
- 預設捷徑: 無

## 外掛程式命令ID

```
EEID_CUSTOMIZE_FAST_VIEW (9082)
```

## 巨集

### \[JavaScript\]

```
editor.ExecuteCommandByID(9082);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 9082
```
