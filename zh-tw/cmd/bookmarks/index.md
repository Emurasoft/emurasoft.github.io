# 書籤類別

|     |     |
| --- | --- |
| **[設置或清除書籤](../bookmarks/bookmark_toggle)** | 為目前的行設置書籤，或清除目前的行的書籤。  |
| **[設置書籤](../bookmarks/bookmark_set)** | 在目前的行設置一個書籤。 |
| **[重設書籤](../bookmarks/bookmark_reset)** | 清除目前的行的書籤。 |
| **[目前文件中的下一個書籤](../bookmarks/bookmark_next_within)** | 轉到目前的文件中的下一個書籤。 |
| **[目前文件中的上一個書籤](../bookmarks/bookmark_prev_within)** | 轉到目前的文件中的上一個書籤。 |
| **[目前文件中的下一個書籤 (循環)](../bookmarks/bookmark_next_around)** | 轉到目前的文件下一個書籤處，如果找不到，就轉到目前文件的第一個書籤處。 |
| **[目前文件中的上一個書籤 (循環)](../bookmarks/bookmark_prev_around)** | 轉到目前的文件上一個書籤處，如果找不到，就轉到目前的文件最後一個書籤處。 |
| **[清除目前文件中的所有書籤](../bookmarks/bookmark_clear)** | 清除目前文件中的所有書籤。 |
| **[倒置目前的文件中的書籤](../bookmarks/bookmark_invert)** | 倒置目前的文件中全部的書籤。 |
| **[剪下目前的文件中書籤標示行](../bookmarks/bookmark_cut)** | 剪下目前的文件中全部的書籤標示行。 |
| **[複製目前的文件中書籤標示行](../bookmarks/bookmark_copy)** | 複製目前的文件中全部的書籤標示行。 |
| **[刪除目前的文件中的書籤標示行](../bookmarks/bookmark_delete)** | 刪除目前的文件中全部的書籤標示行。 |
| **[擷取目前的文件中的書籤標示行到新檔案中](../bookmarks/bookmark_extract)** | 擷取目前的文件中全部的書籤標示行, 並複製到新的檔案。 |
| **[選擇目前的文件中書籤標示行](../bookmarks/bookmark_select)** | 選擇目前的文件中全部的書籤標示行。 |
| **[轉到本組文件的下一個書籤](../bookmarks/bookmark_next)** | 轉到目前的群組中的下一個書籤。 |
| **[轉到本組文件的上一個書籤](../bookmarks/bookmark_prev)** | 轉到目前的群組中的上一個書籤。 |
| **[清除目前的群組中全部的書籤](../bookmarks/bookmark_group_clear)** | 清除目前的群組中全部的書籤。 |
| **[倒置目前的群組中的書籤](../bookmarks/bookmark_group_invert)** | 倒置目前的群組中全部的書籤。 |
| **[刪除目前的群組中書籤標示行](../bookmarks/bookmark_group_delete)** | 刪除目前的群組中所有書籤標示行。 |
| **[擷取目前的群組中所有書籤標示行至新檔案](../bookmarks/bookmark_group_extract)** | 擷取目前的群組中所有書籤標示行並複製到一個新文件中。 |
| **[書籤](../bookmarks/bookmark_bar)** | 顯示書籤自訂欄中的書籤清單。 |
