# 清除輸出列命令

## 摘要

清除輸出列中內容。

## 說明

清除輸出列視窗中的內容。

## 運行方法

- 預設功能表: 無
- [全部命令](../tools/all_commands): **檢視** \> **輸出列** \> **清除輸出**
- 工具列: 無
- 狀態列: 無
- 預設捷徑: 無

## 外掛程式命令ID

```
EEID_OUTPUT_CLEAR (4452)```

## 巨集

## \[JavaScript\]

```
editor.ExecuteCommandByID(4452);
```

## \[VBScript\]

```
editor.ExecuteCommandByID 4452
```
