# 鍵盤配置命令

## 摘要

顯示所有可用的鍵盤快速鍵。

## 說明

顯示可用命令的鍵盤快速鍵清單。

## 運行方法

- 預設功能表: **說明** \> **鍵盤配置**
- [全部命令](../tools/all_commands): **說明** \> **鍵盤配置**
- 工具列: 無
- 狀態列: 無
- 預設捷徑: 無

```
EEID_KEYBOARD_MAP (4298)```

editor.ExecuteCommandByID(4298);
```
