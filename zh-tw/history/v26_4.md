# 版本 26.4

2026 年 10 月 21 日

## 一般新增功能

- [快速檢視模式](../howto/file/file_fast_view)現在支援編輯。您可以在不將巨型檔案載入記憶體的情況下編輯該檔案，包括輸入、貼上、[**復原**](../cmd/edit/edit_undo)/[**重做**](../cmd/edit/edit_redo)、**全部取代**、多重選取，以及 **插入**、**轉換** 和 **排序** 功能表中的大多數命令。在您儲存之前，原始檔案不會變更。{{profree}}
- 快速檢視模式現在支援會變更文檔的 CSV 命令，包括儲存格編輯、[**分割欄**](../cmd/csv/split_column)、[**合併欄**](../cmd/csv/combine_columns)、[**合併行**](../cmd/csv/combine_lines)、[**暫時隱藏引號**](../cmd/csv/csv_hide_quotes)、[**隱藏欄/取消隱藏欄**](../cmd/csv/hide_column)、[**重設欄寬**](../cmd/csv/reset_column_width)，以及 [**靠左對齊**](../cmd/csv/align_left)/[**置中對齊**](../cmd/csv/align_center)/[**靠右對齊**](../cmd/csv/align_right) 命令。{{pro}}
- 在快速檢視模式中儲存巨型檔案時，您可以將編輯內容合併至檔案，或僅將變更儲存至差異檔並保持原始檔案不變。差異檔也會保存各行的位置，因此下次能立即開啟檔案，即使檔案小於最小檔案大小也是如此。{{profree}}
- 快速檢視文檔現在會包含在工作區中，包括其未儲存的編輯內容。{{profree}}
- 在快速檢視模式中，狀態列上新增了 **FAST** 指示器，文檔索引標籤上新增了閃電圖示。雙擊該指示器可在一般模式與快速檢視模式之間切換。{{profree}}
- 有關詳細資訊（包括快速檢視模式中無法使用的功能），請參見[在快速檢視模式中開啟和編輯巨型檔案](../howto/file/file_fast_view)。
- 啟動視窗現在支援 **App 主題** 和 **很暗**。
- 巨集現在以含簽名（BOM）的 UTF-8 儲存，而不是 UTF-16。
- 市集版本和 MSIX 版本：EmEditor 現在會提議移除已解除安裝的 MSI 版本所遺留的檔案關聯，這些關聯曾導致 Windows 無法使用 EmEditor 開啟這些檔案。
- 透過 Microsoft 帳戶同步設定的功能已不再提供，因為 Windows 11 已不再於電腦之間同步市集應用程式的漫遊資料夾。請改用同步資料夾。使用同步資料夾進行同步現在更快、更可靠：不再傳送未變更的設定，不再覆寫其他電腦傳送的較新設定，並且在無法存取資料夾時不會讓 EmEditor 等待。請參見 **自訂** 對話方塊的 [**同步** 頁面](../dlg/customize/sync/index)。
- 工作區的儲存和載入現在更安全：儲存失敗時不再破壞先前的工作區，損壞的工作區或由較新版本儲存的工作區不再被清除，並且包含多個視窗的工作區現在能正確儲存。
- EmEditor MSI 版本的更新檢查程式將在 2027 年 3 月 31 日（UTC）之後停止服務。在此日期之後，EmEditor 將不再檢查更新，並且 [**檢查更新**](../cmd/help/check_updates) 和 [**自訂更新檢查程式**](../cmd/help/customize_update_checker) 將無法使用。
- **註冊資訊** 對話方塊現在會顯示以電腦為單位註冊的電子郵件地址。
- 安裝的檔案更小。不再安裝 pcre.dll、zlib1.dll、vccorlib140.dll 和 msvcp140.dll，並且大多數 DLL、EXE 檔案和外掛程式都變得更小。EXE 和 DLL 檔案總計縮小了 30%。請參見下面的檔案大小。
- 修正了以下問題：
  - 游標順序錯亂的多重選取可能會損壞文字或導致 EmEditor 當機。
  - 在首次繪製含有大量組合字元的行時，EmEditor 可能會當機。
  - **排序** 和 **刪除重複行** 會遺失緊接在僅以 CR 結尾之行後面的空行。
  - 檔案名稱包含「+」，或資料夾名稱包含「#」、「?」或「%」的 Markdown 檔案，無法在 Markdown 預覽中正確預覽。
  - 執行輸出為單行之命令的程式碼片段（例如計算機程式碼片段）會導致 EmEditor 當機。
- 啟動更快。在我們的測試中，主視窗就緒的速度快了 1.93 倍。其他操作也更快了。由於差異檔包含各行的位置，第二次開啟巨型檔案時會更快。請參見下面的測試結果。

## 新增命令

- 在 **全部命令** 功能表的 **檔案** \> **差異** 子功能表中新增了 [**儲存差異**](../cmd/file/fast_view_save_diff)、[**載入差異**](../cmd/file/fast_view_load_diff) 和 [**捨棄差異**](../cmd/file/fast_view_discard_diff) 命令。{{profree}}
- 新增了 [**自訂快速檢視**](../cmd/tools/customize_fast_view) 命令。{{pro}}
- 新增了用於以電腦為單位註冊的 `emeditor /register` 和 `emeditor /unregister` [命令](../howto/file/file_commandline.md)。{{pro}}
- 新增了 `/tail` [命令列選項](../howto/file/file_commandline.md)，用於以快速檢視模式在最後一行開啟檔案，與 `/fast /l -1` 相同。即使仍在為行的位置建立索引，也會立即顯示檔案的結尾。
- 新增了 `/fast` [命令列選項](../howto/file/file_commandline.md)，即使檔案小於 **啟用快速檢視模式所需的最小檔案大小**，也以快速檢視模式開啟檔案。

## 新增選項

- 在 **自訂** 對話方塊中新增了 [**快速檢視** 頁面](../dlg/customize/fast_view/index)。**啟用快速檢視模式所需的最小檔案大小** 文字方塊已從 **進階** 頁面移至此頁面。此頁面也會列出差異檔，您可以刪除它們。{{pro}}
- 在 **自訂** 對話方塊的 [**快速檢視** 頁面](../dlg/customize/fast_view/index) 中新增了 **在快速檢視模式中儲存巨型檔案時提示**、**在快速檢視模式中儲存巨型檔案時，僅將變更儲存至差異檔** 和 **儲存巨型檔案中行的位置，讓下次能立即開啟** 選項。{{pro}}
- 在 **自訂** 對話方塊的 [**狀態列** 頁面](../dlg/customize/status/index) 中新增了 **快速檢視模式** 項目。{{pro}}

## 新增巨集功能 {{pro}}

- 在 **Editor** 對象中新增 [**GetFastViewDiffPath** 方法](../macro/editor/get_fast_view_diff_path)。
- **Document** 與 **Selection** 對象中大多數會變更文檔的屬性與方法，現在可以在快速檢視模式中使用。

## 外掛程式新增功能 {{pro}}

- **與 AI 聊天** 欄現在預設在左側開啟。
- 為 [**EE_INFO** 消息](../plugin/message/ee_info)新增 **EI_GET_FAST_VIEW_DIFF_PATH** 參數，並新增 [**FAST_VIEW_DIFF_PATH_INFO** 結構](../plugin/structure/fast_view_diff_path_info)。
- 新增 **EEID_FAST_VIEW_SAVE_DIFF**、**EEID_FAST_VIEW_LOAD_DIFF**、**EEID_FAST_VIEW_DISCARD_DIFF** 和 **EEID_CUSTOMIZE_FAST_VIEW** 命令 ID。
- 大多數會變更文檔的消息現在可以在快速檢視模式中使用。

### 備註

- 此更新解決了嚴重的安全性問題 [eMudhra Intermediate CA Compromise](https://emudhra.we-have-a-problem.com/)。LSP 功能使用的 Node.js 受此問題影響，因此我們已將隨附的 Node.js 更新至 [v26.12.1](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases) 以解決該問題。
  - 我們對 EmEditor 的全部原始程式碼進行了安全性掃描，發現只有 LSP 受到影響。只要您的 Windows 系統已安裝最新更新，EmEditor 的其他部分都不受影響。EmEditor 使用 Windows 的 CA 憑證，而不是隨附自己的憑證。WebPreview 和 ChatAI 外掛程式使用系統中安裝的 Microsoft Edge。因此，我們建議您儘快更新 Windows 和網頁瀏覽器。
