# 版本 26.3

（發布日期）

## 一般新增功能

- 新增用於超大檔案的 **快速檢視** 模式。快速檢視會以唯讀模式幾乎瞬間打開超大檔案，而無需將整個檔案載入記憶體：EmEditor 會在後臺尋找各行的位置，並且唯讀取目前的顯示的行。打開檔案後，即使 EmEditor 仍在尋找行位置，你也可以立即跳轉到文檔末尾；在行位置尋找完成之前不會顯示行號。大於 **啟用快速檢視模式的最小檔案大小**（預設 4,096 MB）的檔案會自動以快速檢視模式打開，並在以快速檢視模式打開檔案時顯示通知。要在普通模式與快速檢視模式之間切換，請在 **編輯** 功能表中選擇 **快速檢視**。{{profree}}
- 在快速檢視模式下，你可以：
  - 捲動、移動游標、選擇文字（包括縱向選擇），以及複製文字（包括 [**複製為引用文字**](../cmd/edit/edit_copy_prefix)）。{{profree}}
  - 使用 [**跳轉**](../cmd/edit/jump) 和 [**跳轉至標記**](../cmd/edit/tag_jump) 命令跳轉到指定行。{{profree}}
  - 亮顯在 [**亮顯 (1)**](../dlg/properties/highlight1/index) 和 [**亮顯 (2)**](../dlg/properties/highlight2/index) 頁面中的字串、註釋、引號字串、所選文字和標記，並可用 [**添加至標記**](../cmd/edit/add_to_markers) 命令添加標記。{{profree}}
  - 通過 **檢視** 功能表中的 [**標記**](../cmd/view/view_marks) 命令顯示換行符、檔案結尾、 Tab、空格、全形空格和控制字元，並顯示 [**尺規**](../cmd/view/view_ruler)。{{profree}}
  - 使用 **尋找** 對話方塊與 **尋找** 工具列尋找文字，包括規則運算式以及統計符合數。{{profree}}
  - 使用 **尋找** 對話方塊中的 [**抽出** 按鈕](../dlg/find/index) 抽出符合行、檔案名及行、檔案名或符合字串，包括統計高頻字串。{{pro}}
  - 使用「尋找」的 **數字範圍** 和 **模糊符合** 選項。{{pro}}
  - 使用 **批次尋找** 對話方塊中的 [**多項尋找上一個** 和 **多項尋找下一個** 按鈕](../dlg/find/index) 尋找多個字串，包括批次清單中的連結檔案並統計符合數。{{pro}}
  - 使用 **篩選** 工具列篩選行，包括列下拉清單、連結檔案以及亮顯符合項。篩選時會顯示進度對話方塊。{{pro}}
  - 使用 **篩選** 工具列的 [**抽出所有行**](../cmd/search/filterbar_extract) 和 [**抽出符合字串**](../cmd/search/filterbar_extract_matches) 命令抽出篩選後的行或符合字串。{{pro}}
  - 使用 CSV 模式，包括欄標題、選擇列、調整列寬，以及引號儲存格中的換行。{{pro}}
  - 以不同編碼重新加載檔案，包括 **二進位（ASCII 視圖）** 和 **二進位（十六進位視圖）**。{{profree}}
  - 使用 **另存新檔** 以不同編碼或不同換行符儲存檔案。{{profree}}
  - 使用 [**比較** 功能表](../cmd/diff/index)上的命令比較文檔，包括 [**同步捲動**](../cmd/diff/sync_scroll_direct) 和 [**分割視圖**](../cmd/diff/split_view_direct)。快速檢視模式下的文檔也可以與普通模式下的文檔進行比較。{{profree}}
  - 在狀態列檢視游標位置、字元程式碼、選區長度，以及所選數字的總和與平均值。{{profree}}
  - 使用 [**大檔案控制器**](../cmd/view/large_file_bar) 打開檔案的某一部分。{{pro}}
  - 運行巨集和外掛程式，例如 **字數統計** 外掛程式。{{pro}}
  - 運行[外部工具](../cmd/external_tools/index)。{{profree}}
  - 使用 [**AI** 功能表](../cmd/ai/index)上的命令，包括 AI 項目。此功能需要 **ChatAI** 外掛程式。{{pro}}
- 在快速檢視模式下，**尋找** 對話方塊、**尋找** 工具列以及 **篩選** 工具列中的 **漸進式搜尋** 選項將被停用。{{profree}}
- 在快速檢視模式下，打開超大檔案以及在其中進行尋找、篩選與抽出，比上一版本更快，即使檔案遠大於實體記憶體也是如此。請參見下面的測試結果。

### 測試結果：

|  | v26.2 | v26.3 | 對比 |
| --- | --- | --- | --- |
| 打開 | 30.2 秒 | 6.61 秒 | 快 4.57 倍 |
| 尋找 「abcde」（統計符合數） | 37.0 秒 | 7.64 秒 | 快 4.84 倍 |
| 篩選 「abcde」 | 69.6 秒 | 7.53 秒 | 快 9.24 倍 |
| 在「尋找」對話方塊中抽出 「abcde」 | 103 秒 | 9.70 秒 | 快 10.6 倍 |
| 尋找 「[a-c]{5}」（規則運算式，統計符合數） | 198 秒 | 124 秒 | 快 1.60 倍 |

- 隨機 ASCII 檔案（UTF-8，48.4 GB，10 億行）、預設選項、Windows 11、Ryzen 9 7950X。
- 96 GB 實體記憶體，通過 `bcdedit /set {current} truncatememory 17179869184` 限制為 16 GB RAM 以進行模擬。
- v26.3：以快速檢視模式打開。

## 新選項

- 在 **自訂** 對話方塊的 [**進階** 頁面](../dlg/customize/advanced/index)新增 **啟用快速檢視模式的最小檔案大小** 文字方塊。{{profree}}
- 在 [**大檔案控制器**](../cmd/view/large_file_bar)中新增 **快速檢視模式** 核取方塊。{{pro}}

## 新增巨集功能 {{pro}}

- 在 **Document** 對象中新增 [**FastView** 屬性](../macro/document/fast_view)。
- 在 **Document** 對象中新增 [**Text** 屬性](../macro/document/text) 與 [**TextLength** 屬性](../macro/document/text_length)。
- 在 **WebBar** 對象中新增 [**scrollBy** 方法](../macro/web_bar/scrollby)、[**scrollTo** 方法](../macro/web_bar/scrollto)、[**scrollX** 屬性](../macro/web_bar/scrollx) 與 [**scrollY** 屬性](../macro/web_bar/scrolly)。
- 現在，在快速檢視模式下也可以使用 **Document** 與 **Selection** 對象中不會變更文檔的屬性與方法。會變更文檔的屬性與方法在快速檢視模式下將失敗。

## 外掛程式新功能 {{pro}}

- 為 [**EE_INFO** 消息](../plugin/message/ee_info)新增 **EI_GET_FAST_VIEW** 參數。
- 新增 **EEID_FAST_VIEW** 命令 ID。
- 現在，在快速檢視模式下也可以使用用於讀取文檔或移動游標的消息。會變更文檔的消息在快速檢視模式下將失敗。
- **[檔案總管](../howto/plugin/plugin_explorer)**：該外掛程式現在使用 **自訂** 對話方塊中 [**視窗** 頁面](../dlg/customize/window/index)所指定的對話方塊字型大小。
- **[與 AI 聊天](../howto/plugin/plugin_chat_with_ai)**
  - 新增按對話（每個聊天）AI 設定。按對話設定僅對單個聊天生效，修改它不會影響全局設定。
  - 在聊天輸入方塊中新增 AI 模型與工具指示器。它會顯示目前的 AI 模型以及該聊天所選的工具。點擊模型名稱會打開 **設定** 對話方塊。
  - 新增 MCP 串連器，用於將 AI 串連到外部服務。目前僅支持 HTTP 服務器（不支援 STDIO 與 SSE 串連）。
  - 在 **設定** 對話方塊中新增 **MCP 串連器** 頁面。你可以使用 MCP 服務器的 JSON 組態添加新的串連器。
  - 新增 **EmEditor 說明頁面** 串連器。AI 可使用該串連器訪問最新的 EmEditor 說明頁面，從而給出比網頁搜索工具更好的答案。
