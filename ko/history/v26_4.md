# 버전 26.4

2026년 10월 21일

## 새로운 일반 기능

- 빠른 보기 모드에서 편집을 지원하게 되었습니다. 대용량 파일을 메모리에 읽어 들이지 않고 편집할 수 있습니다. 입력, 붙여넣기, [**실행 취소**](../cmd/edit/edit_undo)/[**다시 실행**](../cmd/edit/edit_redo), **모두 바꾸기**, 다중 선택, **삽입**, **변환**, **정렬** 메뉴의 대부분의 명령을 사용할 수 있습니다. 원본 파일은 저장할 때까지 변경되지 않습니다. {{profree}}
- 빠른 보기 모드에서 문서를 변경하는 CSV 명령을 지원하게 되었습니다. 셀 편집, **열 분할**, **열 결합**, **줄 결합**, **임시로 따옴표 숨기기**, **열 숨기기**/**열 숨기기 취소**, **열 너비 재설정**, **왼쪽 맞춤**/**가운데 맞춤**/**오른쪽 맞춤** 명령을 포함합니다. {{pro}}
- 빠른 보기 모드에서 대용량 파일을 저장할 때, 편집 내용을 파일에 병합하거나, 변경 내용만 차이 파일에 저장하고 원본 파일은 그대로 둘 수 있습니다. 차이 파일에는 각 줄의 위치도 저장되므로, 파일이 최소 파일 크기보다 작더라도 다음에 파일을 바로 열 수 있습니다. {{profree}}
- 빠른 보기 모드의 문서가 저장되지 않은 편집 내용을 포함하여 작업 영역에 포함되게 되었습니다. {{profree}}
- 빠른 보기 모드에서 상태 표시줄에 **FAST** 표시기를, 문서 탭에 번개 아이콘을 추가했습니다. 표시기를 두 번 클릭하면 일반 모드와 빠른 보기 모드가 전환됩니다. {{profree}}
- 시작 창에서 **앱 테마** 및 **매우 어둡게**를 지원하게 되었습니다.
- 매크로가 UTF-16 대신 서명(BOM)이 있는 UTF-8로 저장되게 되었습니다.
- Store 및 MSIX 버전: 제거된 MSI 버전이 남긴 파일 연결 때문에 Windows에서 해당 파일을 EmEditor로 열 수 없었던 경우, EmEditor가 그 파일 연결을 제거하도록 제안하게 되었습니다.
- Windows 11이 Store 앱의 로밍 폴더를 컴퓨터 간에 더 이상 동기화하지 않기 때문에, Microsoft 계정을 통한 설정 동기화를 더 이상 사용할 수 없습니다. 대신 동기화 폴더를 사용하십시오. 동기화 폴더를 사용한 동기화가 더 빠르고 안정적이 되었습니다. 변경되지 않은 설정을 보내지 않고, 다른 컴퓨터가 보낸 더 새로운 설정을 덮어쓰지 않으며, 폴더에 액세스할 수 없을 때 EmEditor가 기다리지 않습니다. 자세한 내용은 **사용자 지정** 대화 상자의 **동기화** 페이지를 참조하십시오.
- 작업 영역이 더 안전하게 저장되고 읽어 들여지게 되었습니다. 저장에 실패해도 이전 작업 영역이 손상되지 않고, 손상된 작업 영역이나 더 새로운 버전에서 저장된 작업 영역이 지워지지 않으며, 창이 여러 개인 작업 영역이 올바르게 저장되게 되었습니다.
- MSI 버전의 EmEditor의 업데이트 검사기는 2027년 3월 31일(UTC) 이후에 종료됩니다. 그 이후에는 EmEditor가 업데이트를 확인하지 않으며, [**업데이트 확인**](../cmd/help/check_updates) 및 [**업데이트 확인 사용자 지정**](../cmd/help/customize_update_checker)을 사용할 수 없습니다.
- **등록 정보** 대화 상자에 컴퓨터별 등록의 이메일 주소가 표시되게 되었습니다.
- 설치되는 파일이 작아졌습니다. pcre.dll, zlib1.dll, vccorlib140.dll, msvcp140.dll은 더 이상 설치되지 않으며, 대부분의 DLL, EXE 파일, 플러그인이 작아졌습니다. EXE 및 DLL 파일의 합계는 30% 작아졌습니다. 아래 파일 크기를 참조하십시오.
- 다음 문제를 수정했습니다.
  - 캐럿의 순서가 올바르지 않은 다중 선택으로 인해 텍스트가 손상되거나 EmEditor가 충돌할 수 있었습니다.
  - 결합 문자가 매우 많은 줄을 처음 그릴 때 EmEditor가 충돌할 수 있었습니다.
  - **정렬** 및 **중복된 줄 삭제**에서 CR만으로 끝나는 줄 다음의 빈 줄이 없어졌습니다.
  - 이름에 "+"가 포함되거나 폴더 이름에 "#", "?", "%"가 포함된 Markdown 파일이 Markdown 미리 보기에서 올바르게 표시되지 않았습니다.
  - Calculator 스니펫과 같이 출력이 한 줄인 명령을 실행하는 스니펫에서 EmEditor가 충돌했습니다.
- 시작이 빨라졌습니다. 테스트에서 기본 창이 준비되기까지 1.93배 빨라졌습니다. 다른 작업도 빨라졌습니다. 차이 파일에 각 줄의 위치가 저장되므로, 대용량 파일을 두 번째로 열 때 더 빨라집니다. 아래 테스트 결과를 참조하십시오.

## 새로운 명령

- **모든 명령** 메뉴의 **파일** \> **차이** 하위 메뉴에 **차이 저장**, **차이 로드**, **차이 버리기** 명령을 추가했습니다. {{profree}}
- **빠른 보기 사용자 지정** 명령을 추가했습니다. {{pro}}
- 컴퓨터별 등록을 위한 `emeditor /register` 및 `emeditor /unregister` [명령](../howto/file/file_commandline.md)을 추가했습니다. {{pro}}
- 파일을 빠른 보기 모드로 마지막 줄에서 여는 `/tail` [명령 줄 옵션](../howto/file/file_commandline.md)을 추가했습니다 (`/fast /l -1`과 같음). 줄 위치의 색인을 만드는 중에도 파일의 끝을 즉시 표시합니다.
- 파일 크기가 빠른 보기 모드를 사용하는 최소 파일 크기보다 작아도 파일을 빠른 보기 모드로 여는 `/fast` [명령 줄 옵션](../howto/file/file_commandline.md)을 추가했습니다.

## 새로운 옵션

- **사용자 지정** 대화 상자에 **빠른 보기** 페이지를 추가했습니다. **빠른 보기 모드를 사용할 최소 파일 크기** 텍스트 상자가 **고급** 페이지에서 이 페이지로 이동했습니다. 이 페이지에는 차이 파일 목록도 표시되며, 차이 파일을 삭제할 수 있습니다. {{pro}}
- **사용자 지정** 대화 상자의 **빠른 보기** 페이지에 **빠른 보기 모드에서 대용량 파일을 저장할 때 확인**, **빠른 보기 모드에서 대용량 파일을 저장할 때 변경 내용만 차이 파일에 저장**, **대용량 파일의 줄의 위치를 저장하여 다음에 바로 열 수 있도록 하기** 옵션을 추가했습니다. {{pro}}
- **사용자 지정** 대화 상자의 [**상태** 페이지](../dlg/customize/status/index)에 **빠른 보기 모드** 항목을 추가했습니다. {{pro}}

## 새로운 매크로 기능 {{pro}}

- **Editor** 개체에 **GetFastViewDiffPath** 메서드를 추가했습니다.
- 문서를 변경하는 **Document** 및 **Selection** 개체의 속성과 메서드 대부분을 빠른 보기 모드에서 사용할 수 있게 되었습니다.

## 새로운 플러그인 기능 {{pro}}

- **AI와 채팅** 막대가 기본적으로 왼쪽에 열리게 되었습니다.
- [**EE_INFO** 메시지](../plugin/message/ee_info)에 **EI_GET_FAST_VIEW_DIFF_PATH** 매개 변수를, **FAST_VIEW_DIFF_PATH_INFO** 구조체를 추가했습니다.
- **EEID_FAST_VIEW_SAVE_DIFF**, **EEID_FAST_VIEW_LOAD_DIFF**, **EEID_FAST_VIEW_DISCARD_DIFF**, **EEID_CUSTOMIZE_FAST_VIEW** 명령 ID를 추가했습니다.
- 문서를 변경하는 메시지 대부분을 빠른 보기 모드에서 사용할 수 있게 되었습니다.

### 참고

- 이번 업데이트는 심각한 보안 문제인 [eMudhra Intermediate CA Compromise](https://emudhra.we-have-a-problem.com/)에 대응합니다. LSP 기능은 이 문제의 영향을 받는 Node.js를 사용하므로, 함께 제공되는 Node.js를 [v26.12.1](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases)로 업데이트하여 문제를 해결했습니다.
  - EmEditor 소스 코드 전체에 대한 보안 검사를 수행한 결과, 영향을 받는 부분은 LSP뿐이었습니다. Windows가 최신 업데이트 상태라면 EmEditor의 다른 부분은 영향을 받지 않습니다. EmEditor는 자체 인증서를 포함하지 않고 Windows의 CA 인증서를 사용합니다. WebPreview 및 ChatAI 플러그인은 시스템에 설치된 Microsoft Edge를 사용합니다. 따라서 Windows와 웹 브라우저를 가능한 한 빨리 업데이트할 것을 권장합니다.
