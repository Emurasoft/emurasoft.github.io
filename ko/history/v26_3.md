# 버전 26.3

2026년 10월 7일

## 새로운 일반 기능

- 대용량 파일용 **빠른 보기** 모드를 추가했습니다. 빠른 보기 모드에서는 파일 전체를 메모리에 읽어 들이지 않고 대용량 파일을 읽기 전용으로 거의 즉시 엽니다. EmEditor는 백그라운드에서 각 줄의 위치를 찾고, 화면에 표시되는 줄만 읽어 들입니다. 파일을 열기 시작한 직후부터, EmEditor가 각 줄의 위치를 찾는 동안에도 바로 문서의 끝으로 이동할 수 있습니다. 줄 번호는 각 줄의 위치를 모두 찾을 때까지 표시되지 않습니다. **빠른 보기 모드를 사용할 최소 파일 크기**(기본값 4,096 MB)보다 큰 파일은 자동으로 빠른 보기 모드로 열리며, 파일이 빠른 보기 모드로 열리면 알림이 표시됩니다. 일반 모드와 빠른 보기 모드를 전환하려면 **편집** 메뉴의 **빠른 보기**를 선택하십시오. {{profree}}
- 빠른 보기 모드에서는 다음 작업을 할 수 있습니다.
  - 스크롤, 선택(세로 선택 포함), 복사([**따옴표 내 복사**](../cmd/edit/edit_copy_prefix) 포함), [**점프**](../cmd/edit/jump), [**태그 점프**](../cmd/edit/tag_jump). {{profree}}
  - 강조 표시 문자열, 주석, 따옴표로 묶인 문자열, 마커, [**편집 기호**](../cmd/view/view_marks), [**눈금자**](../cmd/view/view_ruler) 표시 및 [**마커에 추가**](../cmd/edit/add_to_markers). {{profree}}
  - 정규식, **번호 범위** 및 **유사 일치** 옵션을 포함한 텍스트 찾기 및 일치 항목 개수 세기. {{profree}}
  - 이진 보기를 포함한 다른 인코딩으로 다시 읽기, 다른 인코딩이나 줄 바꿈 문자로 **다른 이름으로 저장**. {{profree}}
  - 일반 모드의 문서를 포함한 문서 [**비교**](../cmd/diff/index). {{profree}}
  - 외부 도구 실행. {{profree}}
  - [**찾기** 대화 상자](../dlg/find/index)에서 추출, **일괄 찾기** 대화 상자에서 다중 찾기, **필터** 도구 모음에서 필터 및 추출. {{pro}}
  - CSV 모드, [**대용량 파일 컨트롤러**](../cmd/view/large_file_bar), 매크로, 플러그인, **AI** 메뉴 사용. {{pro}}
- 빠른 보기 모드에서는 책갈피 수가 문서당 100,000개로 제한되고, 세로 스크롤 막대에 표시되는 찾은 문자열 마커 수가 100,000개로 제한되며, **증분 검색** 옵션은 사용할 수 없습니다. {{profree}}
- 다음 기능은 현재 빠른 보기 모드에서 지원되지 않습니다.
  - **미니맵**
  - **Markdown 디자인 보기**
  - **대용량 파일 컨트롤러**의 **열기 필터**
  - **파일** 메뉴의 **검증**, **인쇄**, **인쇄 미리보기**
  - 다중 선택
  - **자동 복사**
  - **책갈피 반전**
  - **구문 검사기**, **윤곽 모음**, **윤곽 가이드**
  - **CSV** 메뉴의 **셀 선택 모드**, **임시로 따옴표 숨기기**, **열 숨기기**/**열 숨기기 취소**, **열 너비 재설정**, **왼쪽 맞춤**/**가운데 맞춤**/**오른쪽 맞춤**
  - 기타 문서를 변경하는 명령
- 빠른 보기 모드에서 **Null 문자 발견시 확인** 및 **잘못된 문자 발견 시 확인** 옵션은 일반 모드처럼 파일 전체가 아니라 파일의 시작 부분만 확인합니다. 자세한 내용은 **속성** 대화 상자의 [**파일** 페이지](../dlg/properties/file/index)를 참조하십시오. {{profree}}
- 빠른 보기 모드에서는 파일이 물리 메모리보다 훨씬 큰 경우에도 대용량 파일 열기와 찾기, 필터, 추출이 이전 버전보다 빨라졌습니다. 아래 테스트 결과를 참조하십시오.

## 새로운 옵션

- **사용자 지정** 대화 상자의 [**고급** 페이지](../dlg/customize/advanced/index)에 **빠른 보기 모드를 사용할 최소 파일 크기** 텍스트 상자를 추가했습니다. {{profree}}
- [**대용량 파일 컨트롤러**](../cmd/view/large_file_bar)에 **빠른 보기 모드** 확인란을 추가했습니다. {{pro}}

## 새로운 매크로 기능 {{pro}}

- **Document** 개체에 **FastView** 속성을 추가했습니다.
- **Document** 개체에 **Text** 속성과 **TextLength** 속성을 추가했습니다.
- **WebBar** 개체에 **scrollBy** 메서드, **scrollTo** 메서드, **scrollX** 속성, **scrollY** 속성을 추가했습니다.
- 문서를 변경하지 않는 **Document** 및 **Selection** 개체의 속성과 메서드를 빠른 보기 모드에서 사용할 수 있게 되었습니다. 문서를 변경하는 속성과 메서드는 빠른 보기 모드에서 실패합니다.

## 새로운 플러그인 기능 {{pro}}

- [**EE_INFO** 메시지](../plugin/message/ee_info)에 **EI_GET_FAST_VIEW** 매개 변수를 추가했습니다.
- **EEID_FAST_VIEW** 명령 ID를 추가했습니다.
- 문서를 읽거나 커서를 이동하는 메시지를 빠른 보기 모드에서 사용할 수 있게 되었습니다. 문서를 변경하는 메시지는 빠른 보기 모드에서 실패합니다.
- **[탐색기](../howto/plugin/plugin_explorer)**: 플러그인이 **사용자 지정** 대화 상자의 [**창** 페이지](../dlg/customize/window/index)에서 지정한 대화 상자 글꼴 크기를 사용하게 되었습니다.
- **AI와 채팅**
  - 채팅별 AI 설정을 추가했습니다. 채팅별 설정은 해당 채팅에만 적용되며, 변경해도 전체 설정에는 영향을 주지 않습니다.
  - 채팅 입력 상자에 AI 모델 및 도구 표시기를 추가했습니다. 채팅의 현재 AI 모델과 선택한 도구가 표시됩니다. 모델 이름을 클릭하면 **설정** 대화 상자가 열립니다.
  - AI를 외부 서비스에 연결하는 MCP 커넥터를 추가했습니다. 현재는 HTTP 서버만 지원합니다(STDIO 및 SSE 연결은 지원하지 않습니다).
  - **설정** 대화 상자에 **MCP 커넥터** 페이지를 추가했습니다. MCP 서버의 JSON 구성을 사용하여 새 커넥터를 추가할 수 있습니다.
  - **EmEditor 도움말 페이지** 커넥터를 추가했습니다. AI는 이 커넥터를 사용하여 최신 EmEditor 도움말 페이지에 액세스할 수 있으므로 웹 검색 도구보다 더 정확한 답변을 제공합니다.
