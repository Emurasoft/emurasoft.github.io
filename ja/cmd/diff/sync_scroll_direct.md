# \[同期スクロール\] コマンド

## 概要

最近表示した 2 個の文書をオプションを指定せずに同期スクロールします。

## 説明

最近表示した 2 個の文書をオプションを指定せずに同期スクロールします。高速ビュー モードの文書も同期スクロールできます。

## 実行方法

- 既定のメニュー: \[比較\] \- \[直接同期スクロール\]
- [すべてのコマンド](../../glossary/allcommands): \[比較\] \- \[直接同期スクロール\]
- ツール バー: なし
- ステータス バー: なし
- 既定のショートカット: なし

## プラグイン コマンド ID

```
EEID_SYNC_SCROLL_DIRECT (4495)```

## マクロ

### \[JavaScript\]

```
editor.ExecuteCommandByID(4495);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4495
```
