# \[比較\] コマンド

## 概要

最近表示した 2 個の文書をオプションを指定せずに比較します。

## 説明

最近表示した 2 個の文書をオプションを指定せずに比較します。

高速ビュー モードの文書も、文書のすべての行の位置を調べた後に比較できます。文書が高速ビュー モードの時は、[[コメントを無視]](ignore_comment)、[[他へコピー]](copy_to_other)、[[すべて他へコピー]](copy_all_to_other)、[[変更をブックマーク]](compare_bookmark) コマンドは使用できません。

## 実行方法

- 既定のメニュー: \[比較\] \- \[直接比較\]
- [すべてのコマンド](../../glossary/allcommands): \[比較\] \- \[直接比較\]
- ツール バー: なし
- ステータス バー: なし
- 既定のショートカット: なし

## プラグイン コマンド ID

```
EEID_COMPARE_DIRECT (4492)```

## マクロ

### \[JavaScript\]

```
editor.ExecuteCommandByID(4492);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4492
```
