# \[大文字と小文字を区別しない\] コマンド

## 概要

文書比較時、大文字と小文字を区別しません。

## 説明

文書比較時、大文字と小文字を区別しません。

## 実行方法

- 既定のメニュー: \[比較\] \- \[大文字と小文字を区別しない\]
- [すべてのコマンド](../../glossary/allcommands): \[比較\] \- \[大文字と小文字を区別しない\]
- ツール バー: なし
- ステータス バー: なし
- 既定のショートカット: なし

## プラグイン コマンド ID

```
EEID_IGNORE_CASES (4501)```

## マクロ

### \[JavaScript\]

```
editor.ExecuteCommandByID(4501);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4501
```
