# \[巨大ファイル コントローラー\] コマンド

## 概要

巨大ファイル コントローラーの表示/非表示を切り替えます。

## 説明

巨大ファイル コントローラーの表示/非表示を切り替えます。

\[高速ビュー モード\] チェック ボックスが選択されている場合、\[適用\]、\[次へ\]、\[戻る\] ボタンは、指定した範囲を[高速ビュー モード](../../howto/file/file_fast_view)で開きます。選択されていない場合は、通常モードで開きます。

## 実行方法

- 既定のメニュー: \[表示\] \- \[巨大ファイル コントローラー\]
- [すべてのコマンド](../../glossary/allcommands): \[表示\] \- \[巨大ファイル コントローラー\]
- ツール バー: なし
- ステータス バー: なし
- 既定のショートカット: なし

## プラグイン コマンド ID

```
EEID_LARGE_FILE_BAR (4449)```

## マクロ

### \[JavaScript\]

```
editor.ExecuteCommandByID(4449);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 4449
```
