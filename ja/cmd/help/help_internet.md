# \[オンライン ヘルプ\] コマンド

## 概要

オンライン ヘルプを表示します。

## 説明

Web ヘルプを表示します。

## 実行方法

- 既定のメニュー: \[ヘルプ\] \- \[設定\] \- \[オンライン ヘルプ\]
- [すべてのコマンド](../../glossary/allcommands): \[ヘルプ\] \- \[設定\] \- \[オンライン ヘルプ\]
- ツール バー: なし
- ステータス バー: なし
- 既定のショートカット: なし

## プラグイン コマンド ID

```
EEID_HELP_INTERNET (3932)```

## マクロ

### \[JavaScript\]

```
editor.ExecuteCommandByID(3932);
```

### \[VBScript\]

```
editor.ExecuteCommandByID 3932
```
