# \[差分を破棄\] コマンド

## 概要

高速ビュー モードの編集内容を破棄し、差分ファイルを削除します。

## 説明

このコマンドは、高速ビュー モードで、文書に編集内容がある場合、または現在のファイルの差分ファイルが存在する場合に使用できます。確認後、差分ファイルに保存された編集内容を含め、文書の編集内容を破棄し、差分ファイルを削除します。元のファイルは変更されません。

開いていないファイルの差分ファイルを削除するには、\[カスタマイズ\] ダイアログ ボックスの [\[高速ビュー\] ページ](../../dlg/customize/fast_view/index)を使用します。詳細は、[高速ビュー モードで巨大ファイルを開いて編集する](../../howto/file/file_fast_view)を参照してください。

## 実行方法

- 既定のメニュー: なし
- [すべてのコマンド](../../glossary/allcommands): \[ファイル\] \- \[差分\] \- \[差分を破棄\]
- ツール バー: なし
- ステータス バー: なし
- 既定のショートカット: なし

## プラグイン コマンド ID

```
EEID_FAST_VIEW_DISCARD_DIFF (23293)
```

## マクロ

```

```

