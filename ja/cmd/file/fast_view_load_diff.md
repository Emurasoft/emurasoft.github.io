# \[差分を読み込む\] コマンド

## 概要

ファイルの差分ファイルに保存された編集内容を高速ビュー モードで適用します。

## 説明

このコマンドは、高速ビュー モードで、現在のファイルの差分ファイルが存在する場合に使用できます。[\[差分を保存\] コマンド](fast_view_save_diff)、または [\[上書き保存\] コマンド](file_save)の \[変更内容だけを保存\] で保存した編集内容を適用し、\[書き換え禁止\] をオフにします。文書に保存されていない編集内容がある場合は、先に保存するかどうかを確認します。

差分ファイルの編集内容は、通常、ファイルを開くときに自動的に適用されます。このコマンドは、たとえば保存されていない編集内容を破棄した後などに、もう一度適用するために使用できます。

ファイルが差分ファイルの保存後に変更された場合、ファイルが異なるエンコードで開かれている場合、または引用符で囲まれたセル内の改行を許可する CSV の設定が異なる場合は、差分ファイルを適用できません。詳細は、[高速ビュー モードで巨大ファイルを開いて編集する](../../howto/file/file_fast_view)を参照してください。

## 実行方法

- 既定のメニュー: なし
- [すべてのコマンド](../../glossary/allcommands): \[ファイル\] \- \[差分\] \- \[差分を読み込む\]
- ツール バー: なし
- ステータス バー: なし
- 既定のショートカット: なし
