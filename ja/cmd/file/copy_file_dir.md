# \[ファイルのフォルダー パスをコピー\] コマンド

## 概要

ファイルのフォルダー パスをコピーしてクリップボードに保存します。

## 説明

ファイルのフォルダー パスをコピーしてクリップボードに保存します。無題の場合はこのコマンドを選択することができません。

## 実行方法

- 既定のメニュー: なし
- [すべてのコマンド](../../glossary/allcommands): \[ファイル\] \- \[コピー\] \- \[ファイルのフォルダー パスをコピー\]
- ツール バー: なし
- ステータス バー: なし
- 既定のショートカット: なし

## プラグイン コマンド ID

```
EEID_COPY_FILE_DIR (4327)```

## マクロ

### \[JavaScript\]

```
document.CopyPath();
```

### \[VBScript\]

```
document.CopyPath
```
