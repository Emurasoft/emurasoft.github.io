# \[差分を保存\] コマンド

## 概要

高速ビュー モードの編集内容と行の位置を、ファイルを書き換えずに EmEditor のデータ フォルダーの差分ファイルに保存し、ファイルを速く開けるようにします。

## 説明

このコマンドは、高速ビュー モードで使用できます。巨大ファイルでは時間がかかることがある元のファイルの書き換えを行わずに、編集内容を差分ファイルに保存します。次回ファイルを開くときに、編集内容が自動的に適用されます。編集内容をファイルに書き込むには、[\[上書き保存\] コマンド](file_save)の \[保存してマージ\] で文書を保存します。

差分ファイルには、ファイルの行の位置も保存されるため、次回は行の位置をもう一度調べずにファイルを開くことができます。文書に編集内容がない場合は、行の位置のみが保存されます。

差分ファイルは、EmEditor のローカル アプリケーション データ フォルダー内の **FastView** フォルダーに保存されます。差分ファイルは、\[カスタマイズ\] ダイアログ ボックスの [\[高速ビュー\] ページ](../../dlg/customize/fast_view/index)で確認や削除ができます。詳細は、[高速ビュー モードで巨大ファイルを開いて編集する](../../howto/file/file_fast_view)を参照してください。

## 実行方法

- 既定のメニュー: なし
- [すべてのコマンド](../../glossary/allcommands): \[ファイル\] \- \[差分\] \- \[差分を保存\]
- ツール バー: なし
- ステータス バー: なし
- 既定のショートカット: なし

## プラグイン コマンド ID

```
EEID_FAST_VIEW_SAVE_DIFF (23291)
```

## マクロ

```

```

