# \[書き換え禁止\] コマンド

## 概要

ファイルの保存の有効/無効を切り替えます。

## 説明

ファイルの保存の有効/無効を切り替えます。

高速ビュー モードでは、書き換え禁止をオンにすると編集もオフになり、オフにすると編集できるようになります。文書に保存されていない編集内容がある場合は、保存するかどうかを確認します。詳細は、[高速ビュー モードで巨大ファイルを開いて編集する](../../howto/file/file_fast_view)を参照してください。

## 実行方法

- 既定のメニュー: \[編集\] \- \[書き換え禁止\]
- [すべてのコマンド](../../glossary/allcommands): \[編集\] \- \[高度な操作\] \- \[書き換え禁止\]
- ツール バー: なし
- ステータス バー: \[書禁\] の項目をダブルクリック
- 既定のショートカット: なし

## プラグイン コマンド ID

```
EEID_READ_ONLY (4113)```

## マクロ

### \[JavaScript\]

```
document.ReadOnly=true;
または
document.ReadOnly=false;
```

### \[VBScript\]

```
document.ReadOnly=true
または
document.ReadOnly=false
```
