# \[高速ビュー\] コマンド

## 概要

通常モードと巨大ファイル用の高速ビュー モードを切り替えます。

## 説明

現在の文書を高速ビュー モードで開き直します。文書がすでに高速ビュー モードの場合は、通常モードで開き直します。高速ビュー モードでは、ファイル全体をメモリに読み込まずに巨大ファイルをほぼ瞬時に開き、ファイルの表示、検索、編集ができます。詳細は、[高速ビュー モードで巨大ファイルを開いて編集する](../../howto/file/file_fast_view)を参照してください。

\[カスタマイズ\] ダイアログ ボックスの [\[高速ビュー\] ページ](../../dlg/customize/fast_view/index)の \[高速ビュー モードを有効にする最小ファイル サイズ\] より大きなファイルは、自動的に高速ビュー モードで開かれます。

文書に保存されていない編集内容がある場合は、モードを切り替える前に保存するかどうかを確認します。このコマンドは、無題の文書では使用できません。

## 実行方法

- 既定のメニュー: \[編集\] \- \[高速ビュー\]
- [すべてのコマンド](../../glossary/allcommands): \[編集\] \- \[高度な操作\] \- \[高速ビュー\]
- ツール バー: なし
- ステータス バー: \[FAST\] の項目をダブルクリック
- 既定のショートカット: なし

## プラグイン コマンド ID

```
EEID_FAST_VIEW (23289)
```

## マクロ

### \[JavaScript\]

```
document.FastView = true;
または
document.FastView = false;
```

### \[VBScript\]

```
document.FastView = True
または
document.FastView = False
```
