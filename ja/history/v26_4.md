# Version 26.4

2026年 10月 21日

## 一般の新機能

- [高速ビュー モード](../howto/file/file_fast_view)で編集できるようになりました。巨大ファイルをメモリに読み込まずに編集できます。入力、貼り付け、[\[元に戻す\]](../cmd/edit/edit_undo)/[\[やり直し\]](../cmd/edit/edit_redo)、\[すべて置換\]、複数選択、および \[挿入\]、\[変換\]、\[並べ替え\] メニューのほとんどのコマンドを使用できます。保存するまで、元のファイルは変更されません。 {{profree}}
- 高速ビュー モードで、セルの編集、[\[列を分割\]](../cmd/csv/split_column)、[\[列を結合\]](../cmd/csv/combine_columns)、[\[行を結合\]](../cmd/csv/combine_lines)、[\[一時的に引用符を非表示\]](../cmd/csv/csv_hide_quotes)、[\[列の非表示\]/\[列の再表示\]](../cmd/csv/hide_column)、[\[列幅をリセット\]](../cmd/csv/reset_column_width)、[\[左揃え\]](../cmd/csv/align_left)/[\[中央揃え\]](../cmd/csv/align_center)/[\[右揃え\]](../cmd/csv/align_right) コマンドなど、文書を変更する CSV コマンドを使用できるようになりました。 {{pro}}
- 高速ビュー モードで巨大ファイルを保存するときに、編集内容をファイルにマージするか、変更内容だけを差分ファイルに保存して元のファイルをそのまま残すかを選択できるようになりました。差分ファイルには行の位置も保存されるため、最小ファイル サイズより小さなファイルでも、次回は即座に開きます。 {{profree}}
- 高速ビュー モードの文書が、保存されていない編集内容を含めて、ワークスペースに含まれるようになりました。 {{profree}}
- 高速ビュー モードの場合に、ステータス バーに **FAST** インジケーターを、文書タブに稲妻のアイコンを表示するようにしました。インジケーターをダブルクリックすると、通常モードと高速ビュー モードを切り替えることができます。 {{profree}}
- 高速ビュー モードで利用できない機能など、詳細は、[高速ビュー モードで巨大ファイルを開いて編集する](../howto/file/file_fast_view)を参照してください。
- スタート ウィンドウで、**アプリ テーマ** と **非常に暗い** をサポートしました。
- マクロを UTF-16 ではなく、UTF-8 (BOM 付き) で保存するようにしました。
- Store 版と MSIX 版: アンインストールされた MSI 版が残したファイルの関連付けのために、Windows がファイルを EmEditor で開けなくなる問題を防ぐため、EmEditor がその関連付けの削除を提案するようにしました。
- Microsoft アカウントを使用した設定の同期は、Windows 11 が Store アプリのローミング フォルダーをコンピューター間で同期しなくなったため、利用できなくなりました。代わりに同期フォルダーを使用してください。同期フォルダーによる同期は、高速で信頼性が高くなりました。変更されていない設定を送信しなくなり、他のコンピューターが送信した新しい設定を上書きしなくなり、フォルダーにアクセスできない場合に EmEditor が待機しなくなりました。[\[カスタマイズ\] ダイアログ ボックスの \[同期\] ページ](../dlg/customize/sync/index)を参照してください。
- ワークスペースの保存と読み込みがより安全になりました。保存に失敗しても以前のワークスペースが破壊されなくなり、壊れたワークスペースや新しいバージョンで保存されたワークスペースが消去されなくなり、複数のウィンドウがあるワークスペースが正しく保存されるようになりました。
- 更新チェッカーは、2027 年 3 月 31 日 (UTC) をもって終了します。それ以降は、MSI 版 EmEditor は更新をチェックせず、[\[更新のチェック\]](../cmd/help/check_updates)と[\[更新チェッカーのカスタマイズ\]](../cmd/help/customize_update_checker)は使用できなくなります。
- \[登録情報\] ダイアログ ボックスに、マシン単位の登録のメール アドレスを表示するようにしました。
- インストールされるファイルが小さくなりました。pcre.dll、zlib1.dll、vccorlib140.dll、msvcp140.dll はインストールされなくなり、ほとんどの DLL、EXE ファイル、プラグインが小さくなりました。EXE ファイルと DLL ファイルの合計は 30% 小さくなりました。下のファイル サイズを参照してください。
- 以下の問題を修正しました。
  - キャレットの順序が正しくない複数選択により、テキストが破損したり、EmEditor がクラッシュしたりすることがある問題。
  - 非常に多くの結合文字を含む行を最初に描画するときに、EmEditor がクラッシュすることがある問題。
  - \[並べ替え\] と \[重複行を削除\] で、CR のみで終わる行の直後の空行が失われる問題。
  - 名前に「+」が含まれる、またはフォルダー名に「#」、「?」、「%」が含まれる Markdown ファイルが、Markdown プレビューで正しく表示されない問題。
  - Calculator スニペットなど、コマンドを実行して 1 行の出力を返すスニペットで、EmEditor がクラッシュする問題。
- 起動が高速になりました。当社のテストでは、新規文書でのメイン ウィンドウの準備完了が、1.93 倍に高速になりました。その他の操作も高速になりました。巨大ファイルを開く操作は、差分ファイルに行の位置が保存されるため、2 回目以降は高速になります。下のテスト結果を参照してください。

- \[2\] v26.3: 通常モード、v26.4: 高速ビュー モード
- \[3\] 「abcde」を「#####」にすべて置換した後に保存、v26.3: 通常モード、v26.4: 高速ビュー モード、\[保存\] \> \[保存してマージ\] を選択

- \[5\] 通常モード

## 新しいコマンド

- **すべてのコマンド** メニューの \[ファイル\] \> \[差分\] サブメニューに、[\[差分を保存\]](../cmd/file/fast_view_save_diff)、[\[差分を読み込む\]](../cmd/file/fast_view_load_diff)、[\[差分を破棄\]](../cmd/file/fast_view_discard_diff) コマンドを追加しました。 {{profree}}
- [\[高速ビューのカスタマイズ\]](../cmd/tools/customize_fast_view) コマンドを追加しました。 {{pro}}
- マシン単位の登録のために、`emeditor /register` と `emeditor /unregister` [コマンド](../howto/file/file_commandline.md)を追加しました。 {{pro}}

## 新しいオプション

- \[カスタマイズ\] ダイアログ ボックスに [\[高速ビュー\] ページ](../dlg/customize/fast_view/index)を追加しました。\[高速ビュー モードを有効にする最小ファイル サイズ\] テキスト ボックスは、\[高度\] ページからこのページに移動しました。このページには差分ファイルも一覧表示され、削除することもできます。 {{pro}}
- [\[カスタマイズ\] ダイアログ ボックスの \[高速ビュー\] ページ](../dlg/customize/fast_view/index)に、\[高速ビュー モードで巨大なファイルを保存する時に確認する\]、\[高速ビュー モードで巨大なファイルを保存する時に変更内容だけを差分ファイルに保存する\]、\[巨大ファイルの行の位置を保存して、次回すぐに開けるようにする\] オプションを追加しました。 {{pro}}
- \[カスタマイズ\] ダイアログ ボックスの [\[ステータス\] ページ](../dlg/customize/status/index)に、\[高速ビュー モード\] 項目を追加しました。 {{pro}}

## 新しいマクロ機能 {{pro}}

- **Editor** オブジェクトに [**GetFastViewDiffPath** メソッド](../macro/editor/get_fast_view_diff_path)を追加しました。
- 文書を変更する **Document** オブジェクトと **Selection** オブジェクトのほとんどのプロパティとメソッドを、高速ビュー モードで使用できるようになりました。

## プラグインの新機能 {{pro}}

- **AIとチャット** バーを、既定で左側に開くようにしました。 {{pro}}
- [**EE\_INFO** メッセージ](../plugin/message/ee_info)に **EI\_GET\_FAST\_VIEW\_DIFF\_PATH** パラメーターと、[**FAST\_VIEW\_DIFF\_PATH\_INFO** 構造体](../plugin/structure/fast_view_diff_path_info)を追加しました。
- **EEID\_FAST\_VIEW\_SAVE\_DIFF**、**EEID\_FAST\_VIEW\_LOAD\_DIFF**、**EEID\_FAST\_VIEW\_DISCARD\_DIFF**、**EEID\_CUSTOMIZE\_FAST\_VIEW** コマンド ID を追加しました。
- 文書を変更するほとんどのメッセージを、高速ビュー モードで使用できるようになりました。
