# Version 26.3

2026年 10月 7日

## 一般の新機能

- 巨大ファイル用の**高速ビュー** モードを追加しました。高速ビュー モードでは、ファイル全体をメモリに読み込まずに、巨大ファイルを書き換え禁止でほぼ瞬時に開きます。EmEditor はバックグラウンドで各行の位置を調べ、表示される行のみを読み込みます。ファイルを開き始めた直後から、EmEditor が各行の位置を調べている間でも、文書の末尾にジャンプできます。行番号は、各行の位置を調べ終わるまで表示されません。[高速ビュー モードを有効にする最小ファイル サイズ] (既定は 4,096 MB) より大きなファイルは自動的に高速ビュー モードで開かれ、ファイルが高速ビュー モードで開かれると通知が表示されます。通常モードと高速ビュー モードを切り替えるには、[編集] メニューの [高速ビュー] を選択します。 {{profree}}
- 高速ビュー モードでは、次の操作ができます。
  - スクロール、カーソルの移動、矩形選択を含む文字列の選択、コピー ([[引用付きコピー]](../cmd/edit/edit_copy_prefix) を含む)。 {{profree}}
  - [[ジャンプ]](../cmd/edit/jump) と [[タグ ジャンプ]](../cmd/edit/tag_jump) コマンドによる行へのジャンプ。 {{profree}}
  - [[強調(1)]](../dlg/properties/highlight1/index) と [[強調(2)]](../dlg/properties/highlight2/index) ページの文字列、コメント、引用符で囲まれた文字列、選択した文字列、マーカーの強調表示と、[[マーカーへ追加]](../cmd/edit/add_to_markers) コマンドによるマーカーの追加。 {{profree}}
  - [表示] メニューの [[記号]](../cmd/view/view_marks) コマンドによる改行、EOF、タブ、空白、全角空白、制御文字の表示と、[[ルーラ]](../cmd/view/view_ruler) の表示。 {{profree}}
  - [検索] ダイアログ ボックスと [検索] ツール バーによる検索 (正規表現、一致数のカウントを含む)。 {{profree}}
  - [検索] ダイアログ ボックスの [[抽出] ボタン](../dlg/find/index)による、一致した行、ファイル名と行、ファイル名、一致した文字列の抽出 (頻出文字列のカウントを含む)。 {{pro}}
  - 検索の [数値範囲] と [あいまい一致] オプション。 {{profree}}
  - [連続検索] ダイアログ ボックスの [[前を複数検索] と [次を複数検索] ボタン](../dlg/find/index)による複数の文字列の検索 (連続一覧のリンク ファイル、一致数のカウントを含む)。 {{pro}}
  - [フィルター] ツール バーによる行のフィルター (列のドロップ ダウン リスト、リンク ファイル、一致の強調表示を含む)。フィルター中は進行状況のダイアログ ボックスが表示されます。 {{pro}}
  - [フィルター] ツール バーの [[すべての行を抽出]](../cmd/search/filterbar_extract) と [[一致した文字列を抽出]](../cmd/search/filterbar_extract_matches) コマンドによる、フィルター結果の行や一致した文字列の抽出。 {{pro}}
  - CSV モード (列見出し、列の選択、列幅の調整、引用符で囲まれたセル内の改行を含む)。 {{pro}}
  - [バイナリ(アスキー表示)] と [バイナリ(16進数表示)] を含む、別のエンコードでの再読み込み。 {{profree}}
  - [名前を付けて保存] による、別のエンコードや改行コードでの保存。 {{profree}}
  - [[比較] メニュー](../cmd/diff/index)のコマンドによる文書の比較 ([[同期スクロール]](../cmd/diff/sync_scroll_direct) と [[分割表示]](../cmd/diff/split_view_direct) を含む)。高速ビュー モードの文書と通常モードの文書も比較できます。 {{profree}}
  - ステータス バーへのカーソル位置、文字コード、選択範囲の長さ、選択した数値の合計と平均の表示。 {{profree}}
  - [[巨大ファイル コントローラー]](../cmd/view/large_file_bar) によるファイルの一部を開く操作。 {{pro}}
  - マクロや、[単語数] プラグインなどのプラグインの実行。 {{pro}}
  - [外部ツール](../cmd/external_tools/index)の実行。 {{profree}}
  - [[AI] メニュー](../cmd/ai/index)のコマンド (AI 項目を含む) の使用。この機能には ChatAI プラグインが必要です。 {{pro}}
- 高速ビュー モードでは、[検索] ダイアログ ボックス、[検索] ツール バー、[フィルター] ツール バーの [インクリメンタル サーチ] オプションは無効になります。 {{profree}}
- 高速ビュー モードでは、ファイルが物理メモリよりはるかに大きい場合でも、巨大ファイルを開く操作と、検索、フィルター、抽出が以前のバージョンより高速になりました。下のテスト結果を参照してください。

### テスト結果

|  | v26.2 | v26.3 | 比較 |
| --- | --- | --- | --- |
| 開く | 30.2 秒 | 6.61 秒 | 4.57 倍に高速化 |
| 「abcde」を検索 (一致数のカウント) | 37.0 秒 | 7.64 秒 | 4.84 倍に高速化 |
| 「abcde」でフィルター | 69.6 秒 | 7.53 秒 | 9.24 倍に高速化 |
| [検索] ダイアログ ボックスで「abcde」を抽出 | 103 秒 | 9.70 秒 | 10.6 倍に高速化 |
| 「[a-c]{5}」を検索 (正規表現、一致数のカウント) | 198 秒 | 124 秒 | 1.60 倍に高速化 |

- ASCII ランダム データのファイル (UTF-8、48.4 GB、10 億行)、既定のオプション、Windows 11、Ryzen 9 7950X。
- 物理メモリは 96 GB、`bcdedit /set {current} truncatememory 17179869184` で 16 GB RAM の環境をシミュレート。
- v26.3: 高速ビュー モードで開いた場合。

## 新しい設定

- [カスタマイズ] ダイアログ ボックスの [[高度] ページ](../dlg/customize/advanced/index)に、[高速ビュー モードを有効にする最小ファイル サイズ] テキスト ボックスを追加しました。 {{profree}}
- [[巨大ファイル コントローラー]](../cmd/view/large_file_bar) に、[高速ビュー モード] チェック ボックスを追加しました。 {{pro}}

## マクロの新機能 {{pro}}

- Document オブジェクトに、[FastView プロパティ](../macro/document/fast_view)を追加しました。
- Document オブジェクトに、[Text プロパティ](../macro/document/text)と [TextLength プロパティ](../macro/document/text_length)を追加しました。
- WebBar オブジェクトに、[scrollBy メソッド](../macro/web_bar/scrollby)、[scrollTo メソッド](../macro/web_bar/scrollto)、[scrollX プロパティ](../macro/web_bar/scrollx)、[scrollY プロパティ](../macro/web_bar/scrolly)を追加しました。
- Document オブジェクトと Selection オブジェクトの、文書を変更しないプロパティとメソッドを、高速ビュー モードで使用できるようになりました。文書を変更するプロパティとメソッドは、高速ビュー モードでは失敗します。

## プラグインの新機能 {{pro}}

- [EE_INFO メッセージ](../plugin/message/ee_info)に、EI_GET_FAST_VIEW パラメーターを追加しました。
- EEID_FAST_VIEW コマンド ID を追加しました。
- 文書を読み取るメッセージやカーソルを移動するメッセージを、高速ビュー モードで使用できるようになりました。文書を変更するメッセージは、高速ビュー モードでは失敗します。
- [エクスプローラ](../howto/plugin/plugin_explorer): [カスタマイズ] ダイアログ ボックスの [[ウィンドウ] ページ](../dlg/customize/window/index)で指定したダイアログ ボックスのフォント サイズを使用するようになりました。
- [AIとチャット](../howto/plugin/plugin_chat_with_ai)
  - チャットごとの AI 設定を追加しました。チャットごとの設定はそのチャットにのみ適用され、変更しても全体の設定には影響しません。
  - チャット入力ボックスに、AI モデルとツールの表示を追加しました。チャットで使用中の AI モデルと選択したツールを表示します。モデル名をクリックすると、[設定] ダイアログ ボックスが開きます。
  - 外部サービスに接続するための MCP コネクタを追加しました。現在は HTTP サーバーのみサポートしています (STDIO と SSE の接続はサポートしていません)。
  - [設定] ダイアログ ボックスに [MCP コネクタ] ページを追加しました。MCP サーバーの構成 JSON を使用して、新しいコネクタを追加できます。
  - [EmEditor ヘルプ ページ] コネクタを追加しました。AI はこのコネクタを使用して最新の EmEditor ヘルプ ページにアクセスできるため、Web 検索ツールよりも的確な回答が得られます。

### 注

- \[P\] EmEditor Professional のみ
- \[PF\] EmEditor Professional と EmEditor Free
