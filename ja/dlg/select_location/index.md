# \[場所の選択\] ダイアログ ボックス

このダイアログ ボックスは、 [\[ハイパーリンク\] コマンド](../../cmd/edit/markdown_hyperlink) または [\[画像\] コマンド](../../cmd/edit/markdown_image) を実行すると表示されます。挿入する場所を指定できます。

## \[場所\] テキスト ボックス

URL やパスなど、場所を指定します。ダイアログ ボックスが開く時に、クリップボードのテキストがここに貼り付けられます。

## \[ローカル ファイルの参照\] ボタン

ローカル ファイルを選択します。現在の文書のフォルダーからの相対パスが \[場所\] テキスト ボックスに入力されます。
